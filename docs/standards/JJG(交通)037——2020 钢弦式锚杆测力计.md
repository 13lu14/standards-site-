修改了钢弦式锚杆测力计承受拉（压）力的计算公式（见 5. 3. 3，2004 年版的附录 B）；

———修改了检定证书内页格式（见附录 B，2004 年版的录 C）；

## 1 范围

本规程适用于钢弦式锚杆测力计的首次检定、后续检定和使用中检查。

## 2 概述

钢弦式锚杆测力计 以下简称 锚杆测力计 主要用于长期检测岩石高边坡和地下围岩内部锚杆的应力，由钢弦、应力套、专用电缆及线圈组成，其结构示意图见图1。

## 4 通用技术要求

## 4.1 外观

锚杆测力计各部分应连接牢固，其表面应无锈斑及裂痕，引出的电缆、护套应无损伤。

## 4.2 铭牌

锚杆测力计应在其显著部位标明其型号、名称、生产厂家、出厂编号及日期等内容。

## 5 计量器具控制

## 5.1 检定条件

#### 5.1.1 检定环境条件

环境条件要求如下：

a） 温度： $2 0 ^ { \circ } \mathrm { C } \pm 5 \mathrm { ^ \circ C }$

b） 相对湿度：应不大于 80％ ；

c） 周围应无影响检定结果的振动、冲击、电磁场及其他干扰源。

#### 5.1.2 检定设备

检定设备及要求如下：

a） 钢弦频率测定仪：分辨力0.01Hz，频率测量相对误差 ±0.05％；

b） 力标准机：0.5 级，力值测量范围覆盖锚杆测力计测量范围。

#### 5.3.3 滞后

滞后检定步骤如下：

a） 锚杆测力计在检定环境条件下放置不少于8h；

![](<images/JJG%28%E4%BA%A4%E9%80%9A%29037%E2%80%94%E2%80%942020%20%E9%92%A2%E5%BC%A6%E5%BC%8F%E9%94%9A%E6%9D%86%E6%B5%8B%E5%8A%9B%E8%AE%A1.assets/15147ea0fbee651545d222dd40de5a689d8e8df816e1a36aa6082d87aa556329.jpg>)<!-- 第 2 页 -->

b） 钢弦频率测定仪通电预热不少于30min；

c） 连接锚杆测力计和钢弦频率测定仪，安装锚杆测力计在力标准机上，按满量程拉力（或压力）对锚杆测力计预拉压3 次，静置5min 后进行正式试验；

d） 进程试验，读取拉力（或压力）为零时钢弦频率测定仪的输出频率值，使用力标准机对锚杆测力计按10％ F·S 逐级加荷至满量程拉力（或压力）值，每级拉力（或压力）保持不小于1min，读取钢弦频率测定仪的输出频率值；

e） 回程试验，加荷到满量程拉力（或压力）值后，按10％ F·S 逐级卸荷至零点拉力（或压力），并读取钢弦频率测定仪的输出频率值；

f） 退回零点拉力（或压力）值后，保持3min，读取拉力（或压力）为零时钢弦频率测定仪的输出频率值；

g） 重复 d） ～ f）的步骤进行3 次循环试验，按公式（1）计算第 $i ( i = 0 , 1 , 2 , 3 \cdots , 1 0 )$ 个检定点第 $j ( j = 1 , 2 , 3 \cdots , 6 )$ 次行程中锚杆测力计灵敏度系数；

$$
k _ {i j} = \frac {F _ {i j}}{f _ {0 j} ^ {2} - f _ {i j} ^ {2}}\tag{1}
$$

式中： $k _ { i j }$ ———第 i 个检定点第j 次行程中锚杆测力计灵敏度系数 $( \mathrm { \ k N / H z } ^ { 2 } )$

$\boldsymbol { F } _ { i j }$ ———第 i 个检定点第j 次行程时力标准机示值（kN）；

$f _ { 0 j }$ ———拉力（或压力）为零时第 j 次行程时钢弦频率测定仪的输出频率值（Hz）；

$f _ { i j }$ ———第 i 个检定点第j 次行程时钢弦频率测定仪的输出频率值（Hz）；

h） 按公式（2）计算 $k _ { i j }$ 的算术平均值；

$$
\bar {k} = \frac {1}{6 0} \sum_ {i = 1} ^ {1 0} \sum_ {j = 1} ^ {6} k _ {i j}\tag{2}
$$

式中： $\bar { k }$ ———所有检定点 $k _ { i j }$ 的算术平均值 $\left( \mathbf { k N } / \mathrm { H z } ^ { 2 } \right)$ ）；

i） 按公式（3）计算零点与各检定点输出频率平方差的理论值；

$$
N _ {i} = \frac {1}{\bar {k}} \overline{F} _ {i}\tag{3}
$$

式中： $N _ { i }$ ———第 i 个检定点在3 次循环试验测量中零点与各检定点输出频率平方差的理论值 $\left( \mathrm { H z } ^ { 2 } \right)$

$\overline{F} _ { i }$ ———第 i 个检定点在3 次循环试验测量中各力标准机示值的算术平均值（kN）；

j） 按公式（4）计算零点第j 次行程的输出频率平方与第 i 个检定点第j 次行程输出频率平方的差；

$$
N _ {i j} = f _ {0 j} ^ {2} - f _ {i j} ^ {2}\tag{4}
$$

k） 按公式（5）计算滞后 ${ \boldsymbol { a } _ { i } } ^ { \prime }$ ，取 $\boldsymbol { a _ { i } } ^ { \prime }$ 中绝对值最大值为滞后的检定结果；

$$
a _ {i} ^ {\prime} = \frac {\overline{N} _ {i J} - \overline{N} _ {i H}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{5}
$$

式中： $\overline{N} _ { i J }$ ———3 次进程测量各检定点对应的 $N _ { i j }$ 算术平均值 $( \mathrm { H } \mathbf { z } ^ { 2 } )$

$\overline{N} _ { i H }$ ———3 次回程测量各检定点对应的 $N _ { i j }$ 算术平均值 $\left( \mathrm { H z } ^ { 2 } \right)$

$\bar{f} _ { 0 }$ ———3 次循环试验测量中拉力（或压力）为零时钢弦频率测定仪的输出频率的算术平均值（Hz）；

<!-- 第 3 页 -->

$\bar { f } _ { 1 0 }$ ———3 次循环试验测量中满量程拉力（或压力）时钢弦频率测定仪的输出频率的算术平均值（Hz）；

#### 5.3.4 不重复度

不重复度的检定试验步骤与滞后的检定试验 a） ～j）步骤相同，按公式（6）计算不重复度 ${ \boldsymbol { a } _ { i } } ^ { \prime \prime }$ ，取 ${ \boldsymbol { a } _ { i } } ^ { \prime \prime } |$ 中最大值为不重复度的检定结果。

$$
a _ {i} ^ {\prime \prime} = \frac {\left| \Delta N _ {\mathrm{R}} \right|}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{6}
$$

式中： $\Delta N _ { \mathrm { R } }$ ————3 次循环测量中各检定点输出频率平方差的最大值 $\left( \mathrm { H z } ^ { 2 } \right)$

#### 5.3.5 非线性度

非线性度的检定试验步骤与滞后的检定试验 a） ～j）步骤相同，按公式（7）计算非线 性度 $L _ { i }$ ，取 $L _ { i }$ 中绝对值最大值为非线性度的检定结果。

$$
L _ {i} = \frac {\overline{N} _ {L} - N _ {i}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{7}
$$

式中： $\overline{N} _ {L}$ ———3 次循环测量中各检定点的输出频率平方差的算术平均值 $\left( \mathrm { H z } ^ { 2 } \right)$ ；

#### 5.3.6 综合误差

综合误差的检定试验步骤与滞后的检定试验 a） ～j）步骤相同，按公式（8）计算综合误差 $\varepsilon _ { \mathrm { { i C } } }$ ，取 $\varepsilon _ { \mathrm { { i C } } }$ 中绝对值最大值为综合误差的检定结果。

$$
\varepsilon_ {i \mathrm{C}} = \frac {N _ {i j} - N _ {i}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{8}
$$

## 5.4 检定结果的处理

经检定合格的锚杆测力计，发给检定证书，检定证书内页格式见附录 B；检定不合格的锚杆测力计，发给检定结果通知书，并注明不合格项目，检定结果通知书内页格式见附录 C

锚杆测力计的检定周期一般不超过1 年。

 引 言

公路机电设施在提高公路运营管理效率、保障交通运输安全等方面发挥了重要的作用,在公路行业获得了广泛的应用。JT/T 1431《公路机电设施主要用电设备能效等级及评定方法》系列标准根据不同公路机电设施产品功能要求、性能指标和能耗特点等的不同将标准分为五个部分。

———第1部分:LED车道控制标志。 明确了LED车道控制标志产品的能效评定方法和能效等级划分。

———第2 部分:公路隧道通风机。 明确了公路隧道通风机产品的能效评定方法和能效等级划分。

———第3 部分:公路隧道照明系统。 明确了公路隧道照明系统的能效评定方法和能效等级划分。

———第4 部分:公路 LED 可变信息标志。 明确了公路 LED 可变信息标志产品的能效评定方法和能效等级划分。

———第5 部分:公路 LED 照明灯具。 明确了公路 LED 照明灯具产品的能效评定方法和能效等级划分。

公路 LED 可变信息标志作为文件第4 部分,能效等级的指标综合考虑了国内生产企业的整体水平,标准内容力求满足适用性、先进性、可操作性的编制原则。

## 1 范围

本文件规定了公路 LED 可变信息标志的基本要求、能效等级和评定方法。

本文件适用于公路 LED 可变信息标志的能效等级评定。 公路 LED 可变限速标志以及城市、港口、铁路和码头用 LED 可变信息标志参照使用。

## 3 术语及定义

GB/T 23828 确定的以及下列术语及定义适用于本文件。

### 3.1 像素 pixel

由单只或多只 LED 管组成,且可控制其发光或熄灭状态的基本显示单元。

[来源:GB / T 23828—2009,3. 1,有修改]

### 3.2 显示屏 display screen

由 LED 像素组成,用于显示公路 LED 可变信息标志内容的发光矩阵及其支撑底板。

### 3.3 全屏亮度 screen luminance

L

公路 LED 可变信息标志显示屏全部像素点亮条件下的显示屏亮度值,在数值上用单位面积的平均发光强度表示。单位为坎德拉每平方米(cd/m<sup>2</sup>)。

### 3.4 显示屏面积 the area of display screen

S

公路 LED 可变信息标志显示屏的长度乘以宽度,不包含显示屏边框尺寸。

注:单位为平方米(m<sup>2</sup>)。

### 3.5 公路 LED 可变信息标志能效 energy efficiency for LED variable message signs of highwayη

实测公路 LED 可变信息标志功率值与其显示屏面积比。

注:单位为瓦每平方米 $\left( \mathbb { W } / \mathrm { m } ^ { 2 } \right)$ 。

## 4 基本要求

### 4.1 公路 LED 可变信息标志技术要求应符合 GB/T 23828 的规定。

### 4.2 公路 LED 可变信息标志功能要求应符合 GB/T 23828 的规定。

### 4.3 当 $8 0 0 0 \ \mathrm { c d / m } ^ { 2 } \leqslant L \leqslant 8 \ 4 0 0 \ \mathrm { c d / m } ^ { 2 }$ 的工作条件下,功率因数应不小于0.95。

### 4.4 除特殊应用场所要求的高亮度公路 LED 可变信息标志产品外,一般场所用的公路 LED 可变信息标志显示屏全屏最大亮度宜不大于 $2 0 0 0 0 ~ \mathrm { c d } / \mathrm { m } ^ { 2 }$ 。

### 4.5 公路 LED 可变信息标志像素宜根据现场纵向安装高度、横向视认角度、车道宽度等进行配光设计,使其光通量投射到视认区域。静态视认距离和动态视认距离应满足 GB/T 23828 的要求。

### 4.6 公路 LED 可变信息标志应具备节能调光控制功能,公路 LED 可变信息标志夜间显示屏亮度应符合表 1 的要求。

## 6 评定方法

### 6.1 试验条件

#### 6.1.1 公路 LED 可变信息标志亮度测试环境温度和相对湿度应满足 GB/T 23828 的规定。

#### 6.1.2 公路 LED 可变信息标志能效测试条件为 $8 \ 0 0 0 \ \mathrm { c d / m } ^ { 2 } \leqslant L \leqslant 8 \ 4 0 0 \ \mathrm { c d / m } ^ { 2 } ($ (去除自然光环境亮度后)。 测试时亮度计观测轴与显示屏的法线光轴的视认角应不大于 $1 5 ^ { \circ } { }$ ,测试直线距离宜不小于50 m。<!-- 第 2 页 -->

### 6.2 试验仪器

#### 6.2.1 亮度计

亮度计的计量性能应符合 JJG 211—2005 规定的一级要求。

#### 6.2.2 功率测量仪表

功率测量仪表的准确度等级应满足 JJG 124—2005 规定的 0.5 级。

### 6.3 检测样本数量

公路用 LED 可变信息标志进行能效评定测试时,抽样数量应不少于抽样批次总数量的 10%,且抽样样品数量应不少于 3 台完整的产品。当抽样批次总数量少于 3 台时,按全部抽样的样品数量进行抽样。

### 6.4 试验方法

#### 6.4.1 接通电源使公路 LED 可变信息标志 L 达到测试条件要求的亮度。

#### 6.4.2 亮度测试分别在公路 LED 可变信息标志显示屏上均匀选择不少于 7 个位置 在不小于 50 m 的测试距离用亮度计测试其亮度值,记为 $L _ { i } ( i = 1 \ : , 2 \ : , 3 \ : , 4 \ : , 5 \ : , 6 \ : , 7 ) \ : _ { }$ 。 按照式(1)计算 $L _ { \mathrm { o } }$

$$
L = \frac {\sum_ {i = 1} ^ {n} L _ {i}}{n}\tag{…… (1}
$$

式中:

$L _ { i }$ ———显示屏上某一测试点的亮度值 单位为坎德拉每平方米 $( \mathrm { c d } / \mathrm { m } ^ { 2 } )$ ;

$n$ ———显示屏不同测试位置, $n \geqslant 7$ ；

#### 6.4.3 功率测试

维持公路 LED 可变信息标志 L 在测试条件要求的亮度,采用功率测量仪表实测公路 LED 可变信息标志功率值,连续测试三次,每次间隔 5 min~10 min,实测功率值,分别记为 $W _ { 1 } , W _ { 2 } , W _ { 3 }$,单位为瓦(W)。

#### 6.4.4 平均功率计算按照式(2)计算公路 LED 可变信息标志平均功率值 $( \overline { { W } } )$ 。

$$
\overline{W} = \frac {W _ {1} + W _ {2} + W _ {3}}{3}\tag{2}
$$

式中 :

$\overline { W }$ ———公路 LED 可变信息标志平均功率值,单位为瓦(W);

$W _ { 1 } , W _ { 2 } , W _ { 3 }$ ———公路 LED 可变信息标志功率值连续测试三次的功率值,单位为瓦(W)；

### 6.5 能效计算

按照式(3)计算公路 LED 可变信息标志的能效(η)。<!-- 第 3 页 -->

$$
\eta = \frac {\overline{W}}{S}\tag{……(3}
$$

式中:

$\overline { W }$———公路 LED 可变信息标志不同亮度条件下实测平均功率值,单位为瓦(W)；

### 6.6 能效等级评定

将公路 LED 可变信息标志计算的能效(η)与表 2 中的数据进行比较,确定所测试的公路 LED 可变信息标志的能效等级。

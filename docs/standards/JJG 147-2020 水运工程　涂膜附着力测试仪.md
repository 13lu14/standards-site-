 水运工程 涂膜附着力测试仪检定规程

## 1 范围

本规程适用于涂膜附着力测试仪的首次检定、后续检定和使用中检查。

## 2 概述

涂膜附着力测试仪是用于测定各种涂膜对被涂物表面的附着能力的仪器

涂膜附着力测试仪主要由机架、测量传感器、万向轴、锭子和显示屏组成，结构示意见图1。

涂膜附着力测试仪的工作原理是在规定的加载速率下 向试样的胶结面上施加垂直均匀的拉力，以测定涂膜与底材之间附着破坏时的力值。

## 4 通用技术要求

## 4.1 外观涂膜附着力测试仪主机表面应牢固，不应有脱落、划伤、锈迹等缺陷，不应有刻痕和脱漆。

## 4.2 铭牌涂膜附着力测试仪应有清晰的铭牌，标有产品名称、型号、编号、出厂日期以及生产单位。

## 5 计量器具控制

## 5.1 检定条件
#### 5.1.1 检定环境条件环境条件要求如下：

a） 温度： $2 0 ^ { \circ } \mathrm { C } \pm 5 \mathrm { ^ \circ C }$

b） 相对湿度：应不大于80％；

c） 测量点周围500mm 内无较强磁场。

#### 5.1.2 检定设备检定设备及要求如下：

a） 标准测力仪：0. 3 级及以上；

b） 游标卡尺：最大允许误差 ±0. 03mm。

## 5.3 检定方法
#### 5.3.1 外观采用目测和手检的方法检查外观。

#### 5.3.2 铭牌采用目测的方法检查铭牌。

#### 5.3.3 锭子直径误差采用游标卡尺沿两个垂直方向测量锭子直径，计算其算术平均值，按公式（1）计算锭子直径误差 $\Delta d _ { \scriptscriptstyle \odot }$

![](images/JJG%20147-2020%20%E6%B0%B4%E8%BF%90%E5%B7%A5%E7%A8%8B%E3%80%80%E6%B6%82%E8%86%9C%E9%99%84%E7%9D%80%E5%8A%9B%E6%B5%8B%E8%AF%95%E4%BB%AA.assets/9a480eef3334b19eb7c10a77fec5ec6aba1a5c7a2d98a082da389e84cc072c73.jpg)
<!-- 第 2 页 -->

$$
\Delta d = \bar {d} - d\tag{1}
$$

式中： $: \overline { { d } } $ ———锭子直径的算术平均值（mm）；

$d $ ———锭子的标称直径（mm）；

#### 5.3.4 力值
5.3.4.1 相对误差
力值相对误差检定步骤如下：

a） 安装涂膜附着力测试仪至工作台上，与标准测力仪连接，调节标准测力仪至零点；

b） 预加额定负荷至涂膜附着力测试仪满量程，卸载至 0 负荷，循环 3 次，每次卸荷与加荷之间等待30s；

c） 检查标准测力仪回零情况，如未回零则重新调整零点；

d） 按涂膜附着力测试仪量程的10％增量逐级递增负荷，共加载10 次，加至每级负荷后稳定30s，记录读数值；

e） 每个检定点连续测量3 次并记录数据，取3 次测量力值的算术平均值 $\overline{F} _ { i } ^ { \prime }$ 作为测量结果；

f） 按公式（2）计算各测量点相对误差 $\theta _ { \mathrm { f } }$ ，选取绝对值最大的相对误差作为检定结果。

$$
\theta_ {\mathrm{f}} = \frac {\overline{F} _ {i} ^ {\prime} - F _ {i}}{F _ {i}}\tag{2}
$$

式中： $\overline{F} _ { i } ^ { \prime }$ ———第 i 次测量时3 次施加力的算术平均值（kN）；

$F _ { i }$ ———第 i 次测量时施加的标准力值（kN）；

5.3.4.2 重复性
力值重复性检定步骤如下：

a） 按
5.3.4.1 中步骤 a）连接涂膜附着力测试仪和标准测力仪；

b） 重复加载量程中值3 次，记录涂膜附着力测试仪示值；

c） 按公式（3）计算力值重复性 R。

$$
R = \frac {F _ {\max} - F _ {\min}}{\overline{F} _ {i} ^ {\prime}}\tag{3}
$$

式中： $F _ { \mathrm { m a x } }$ ———3 次测量示值中的最大值（kN）；

$F _ { \mathrm { m i n } }$ ———3 次测量示值中的最小值（kN）；

$\overline{F} _ { i } ^ { \prime }$ ———3 次施加力的算术平均值（kN）；

5.3.4.3 回零差
力值回零差检定步骤如下：

a） 按
5.3.4.1 中 a） ～c）步骤对涂膜附着力测试仪进行预加荷并回零后，在每次测量序列开始之前记录零点时涂膜附着力测试仪示值；

b） 在完成第j 次测量序列后，完全卸除负荷，等待30s 后记录零点时涂膜附着力测试仪示值；

c） 按公式（4）计算力值回零差 $Z _ { \mathrm { { r } } }$ ；

$$
Z _ {\mathrm{r}} = \frac {f _ {j} ^ {\prime} - f _ {j}}{F _ {j}} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{4}
$$
<!-- 第 3 页 -->
式中： $f _ { j } ^ { \prime }$ ———第 $j$ 次测量序列卸力后零点值（kN）；

$f _ { j }$ ———第 $j$ 次测量序列加荷前零点值（kN）；

$F _ { j }$ ———第j 次测力序列额定负荷下的力值（kN）；

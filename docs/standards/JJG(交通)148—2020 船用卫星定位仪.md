 船用卫星定位仪检定规程

## 1 范围

本规程适用于船用卫星定位仪的首次检定、后续检定和使用中检查。

## 2 术语

GB／T 19391—2003 界定的及以下术语和定义适用于本规程。

## 2.1 船用卫星定位仪 shipborne satellite positioning device

利用卫星定位技术为船舶提供连续稳定的时间、位置、速度等导航信息的定位设备。

## 2.2 GNSS 信号模拟器 GNSS signal simulator

一种能够按照 BDS／GPS／GLONASS／GALILEO 的卫星信号原理特性和用户定义仿真参数，产生模拟卫星导航信号的设备。

## 3 概述

船用卫星定位仪是一种广泛应用于水运工程测量 海洋工程测量 海洋资源调查等领域的定位设备 其可在静态或动态的条件下 以无差分定位 实时动态伪距差分定位（RTD）、星基差分实时精密单点定位（PPP）和实时动态载波相位差分定位（RTK）的方式进行定位。

船用卫星定位仪主要由接收天线和接收主机两部分组成。

船用卫星定位仪通过接收全球导航卫星系统 的广播信号 采用空间的距离交会原理进行三维位置空间归算，同时接收差分台站发送的位置修正信息，获得高准确度等级的定位结果 工作原理示意图如图 所示

## 5 通用技术要求

## 5.1 外观

#### 5.1.1 船用卫星定位仪表面应光洁、无锈蚀，无明显的划痕、裂缝和变形。5 1 2 船用卫星定位仪各个部件之间的连接应坚固 牢靠 各个按键应反应灵敏 无卡滞现象。

## 5.2 铭牌船用卫星定位仪应有清晰的铭牌，标有产品名称、产品型号、生产厂家、出厂编号及出厂日期等。

## 6 计量器具控制

## 6.1 检定条件

#### 6.1.1 环境条件

6.1.1.1 温度与湿度
温度与湿度环境条件要求如下：

a） 温度：室内 $1 5 ^ { \circ } \mathrm { C } \sim 3 5 ^ { \circ } \mathrm { C }$ ，室外 $- 1 5 ^ { \circ } \mathrm { C } \sim 4 5 \mathrm { ^ \circ C }$ ；

b） 相对湿度：20％ ～ 90％ 。

6.1.1.2 检定场地
检定场地环境条件要求如下：

室内场地应采用吸波材料和金属屏蔽体组建的微波暗室或远离高压输电线路和微波无线电信号的试验环境 以排除外界电磁干扰和多路径效应 并应建有安装好的固定测试平台 无机械振动

b） 室外场地应建有若干已知观测点，各个已知观测点的三维坐标位置准确度等级应满足 D 级 GNSS 测量的要求，各个已知观测点周围应无显著电磁信号干扰，且环视高度角 $1 0 ^ { \circ }$ 以上无障碍物。

#### 6.1.2 检定设备检定设备要求如下：

a） GNSS 信号模拟器：支持船用卫星定位仪所适用的 GNSS 系统，可自定义仿真所需标准场景，仿真信号通道数量大于12，信号功率范围 －140 dBm ～－100 dBm，伪距相位控制最大允许误差优 $\Gamma \pm 0 . 0 5 \textrm { m }$ ，信号相位噪声（抖动）小于 0. 1 rad（rms），谐杂波抑制水平大于40 dBc，内部时钟稳定度小于 $5 \times 1 0 ^ { - 8 } / \mathrm { d }$ ；

b） 天线对中基座：可旋转强制对中杆，自转的同心度小于1 mm。

#### 6.3.3 示值误差

6.3.3.1 静态定位示值误差静态定位示值误差检定步骤如下：

a） 安装船用卫星定位仪的接收天线到天线对中基座。

b） 安装天线对中基座到一个已知三维直角坐标 $( X _ { 0 } , Y _ { 0 } , Z _ { 0 } )$ 的静态观测点上，并进行对中整平 使天线中心与观测点中心重合

启动船用卫星定位仪 设置定位数据更新频率为 接收主机上显示卫星状态为良好或可用时 连续记录时间不少于

d） 将船用卫星定位仪 2h 采集的全部定位数据导出，按式（1）计算静态平面示值误差。

$$
\Delta p = \frac {\sum_ {i = 1} ^ {n} \sqrt {\left(X _ {i} - X _ {0}\right) ^ {2} + \left(Y _ {i} - Y _ {0}\right) ^ {2}}}{n}\tag{1}
$$

<!-- 第 3 页 -->

式中： $\Delta p$ ———静态平面示值误差（m）；

$X _ { i }$ ———船用卫星定位仪在空间直角坐标系X轴上的位置示值（m）；

$Y _ { i }$ ———船用卫星定位仪在空间直角坐标系 Y轴上的位置示值（m）；

$X _ { 0 }$ ———静态观测点在空间直角坐标系X轴上的已知位置（m）；

$Y _ { 0 }$ ———静态观测点在空间直角坐标系 Y轴上的已知位置（m）；

$n$ ———定位数据组数；

e） 按式（2）计算静态高程示值误差。

$$
\Delta h = \frac {\sum_ {i = 1} ^ {n} \sqrt {\left(Z _ {i} - Z _ {0}\right) ^ {2}}}{n}\tag{2}
$$

式中： $\Delta h$ ———静态高程示值误差（m）；

$Z _ { i }$ ———船用卫星定位仪在空间直角坐标系 Z 轴上的位置示值（m）；

$Z _ { 0 }$ ———静态观测点在空间直角坐标系 Z 轴上的已知位置（m）；

6.3.3.2 动态定位示值误差动态定位示值误差检定步骤如下：

a） 安装船用卫星定位仪至室内场地的测试平台上，启动船用卫星定位仪，设置定位数据更新频率为 $1 0 \mathrm { H z } $ ；

b） 启动GNSS信号模拟器，设置模拟速度 $5 \mathrm { m / s }$ ，直线运动时间 $1 0 \mathrm { { m i n } }$ ；

c） 船用卫星定位仪接收GNSS信号模拟器输出的射频仿真定位信号 $( X _ { i } ^ { \prime } , Y _ { i } ^ { \prime } , Z _ { i } ^ { \prime } )$ ，接收主机记录定位数据；

d） 将船用卫星定位仪10 min 采集的全部定位数据导出，按式（3）计算动态平面示值误差。

$$
\Delta m p = \frac {\sum_ {i = 1} ^ {n} \sqrt {\left(X _ {i} - X _ {i} ^ {\prime}\right) ^ {2} + \left(Y _ {i} - Y _ {i} ^ {\prime}\right) ^ {2}}}{n}\tag{3}
$$

式中： $\Delta m p$ ———动态平面示值误差（m）；

$X _ { i }$ ———船用卫星定位仪在空间直角坐标系X轴上的位置示值（m）；

$Y _ { i }$ ———船用卫星定位仪在空间直角坐标系 Y轴上的位置示值（m）；

$X _ { i } ^ { \prime }$ ———仿真信号在空间直角坐标系X轴上的已知位置（m）；

$Y _ { i } ^ { \prime }$ ———仿真信号在空间直角坐标系 Y轴上的已知位置（m）；

e） 按式（4）计算动态高程示值误差。

$$
\Delta m h = \frac {\sum_ {i = 1} ^ {n} \sqrt {\left(Z _ {i} - Z _ {i} ^ {\prime}\right) ^ {2}}}{n}\tag{4}
$$

式中： $\Delta m h$ ———动态高程示值误差（m）；

$Z _ { i }$ ———船用卫星定位仪在空间直角坐标系 Z 轴上的位置示值（m）；

$Z _ { i } ^ { \prime }$ ———仿真信号在空间直角坐标系 $Z$ 轴上的已知位置（m）；

6.3.3.3 速度示值误差速度示值误差检定步骤如下

a） 安装船用卫星定位仪至室内场地的测试平台上，启动船用卫星定位仪，设置定位

<!-- 第 4 页 -->

数据更新频率为10Hz。

b） 启动GNSS 信号模拟器，分别设置模拟速度 $\mathrm { 1 m / s }、\mathrm { 2 m / s }、\mathrm { 3 m / s }、\mathrm { 4 m / s }、\mathrm { 5 m / s }、\mathrm { 6 m / s }、\mathrm { 7 m / s }、\mathrm { 8 m / s }、\mathrm { 9 m / s }、\mathrm { 10 m / s }$ ，运动时间均为 $2 \mathrm { m i n }$ ；

c） 船用卫星定位仪接收的GNSS信号模拟器输出的射频仿真速度信号 ｖ′ｉ 即为标准速度。

d） 按式（5）计算速度示值误差。

$$
\Delta v = \frac {\sum_ {i = 1} ^ {n} \sqrt {(v _ {i} - v _ {i} ^ {\prime}) ^ {2}}}{n}\tag{5}
$$

式中： $\Delta v$ ———速度示值误差（m／ s）；

$v _ { i }$ ———船用卫星定位仪速度示值（m／s）；

#### 6.3.4 重复性船用卫星定位仪静态定位重复性检定步骤如下：

a） 按
6.3.3.1 的方法重复测量6 次，按式（6）计算静态平面定位重复性。

$$
\sigma_ {\mathrm{p}} = \sqrt {\frac {\sum_ {i = 1} ^ {n} (D _ {i} - \overline{D}) ^ {2}}{n - 1}}\tag{6}
$$

$$
D _ {i} = \sqrt {\left(X _ {i} - X _ {0}\right) ^ {2} + \left(Y _ {i} - Y _ {0}\right) ^ {2}}\tag{7}
$$

式中： $\sigma _ { \mathrm { { p } } }$ ———静态平面定位重复性（m）；

$D _ { i }$ ———船用卫星定位仪平面坐标示值 $( X _ { i } , Y _ { i } )$ 到静态观测点平面坐标 $( X _ { 0 } , Y _ { 0 } )$ 的距离（m）；

$\bar{D}$ ———距离 $D _ { i }$ 的算术平均值（m）；

b） 按式（8）计算静态高程定位重复性。

$$
\sigma_ {H} = \sqrt {\frac {\sum_ {i = 1} ^ {n} \left(H _ {i} - \overline{H}\right) ^ {2}}{n - 1}}\tag{8}
$$

$$
H _ {i} = Z _ {i} - Z _ {0}\tag{9}
$$

式中： $\sigma _ { H }$ ———静态高程定位重复性（m）；

$H _ { i }$ ———船用卫星定位仪高程示值 $Z _ { i }$ 与静态观测点高程值 $Z _ { 0 }$ 的高程差（m）；

$\overline{H}$ ———高差 $H _ { i }$ 的算术平均值（m）；

 引 言

公路机电设施在提高公路运营管理效率、保障交通运输安全等方面发挥了重要的作用,在公路行业获得了广泛的应用。JT/T 1431《公路机电设施主要用电设备能效等级及评定方法》系列标准根据不同公路机电设施产品功能要求、性能指标和能耗特点等的不同将标准分为五个部分。

———第1 部分:LED 车道控制标志。 明确了 LED 车道控制标志产品的能效评定方法和能效等级划分。

———第2 部分:公路隧道通风机。 明确了公路隧道通风机产品的能效评定方法和能效等级划分。

———第3 部分:公路隧道照明系统。 明确了公路隧道照明系统的能效评定方法和能效等级划分。

———第4 部分:公路LED 可变信息标志。 明确了公路LED 可变信息标志产品的能效评定方法和能效等级划分。

———第5 部分:公路 LED 照明灯具。 明确了公路 LED 照明灯具产品的能效评定方法和能效等级划分。

公路隧道照明系统作为文件第3 部分,能效评定以公路隧道照明系统的应用效果符合公路隧道照明设计的规定为前提,能效等级的指标综合考虑了国内公路隧道照明系统的整体水平,标准内容力求满足适用性、先进性、可操作性的编制原则。

## 6 评定方法

### 6.1 试验条件

#### 6.1.1 隧道照明系统所用光源累计燃点时间应不小于 $1 0 0 \ \mathrm { h } _ { \mathrm { ~ c ~ } }$ 。

#### 6.1.2 照明测量应在清洁和干燥的路面上进行,且隧道照明系统处于正常工作状态下。

#### 6.1.3 照明测量过程中应避免干扰光射入光接收器,并应防止各类人员和物体对光接收器造成遮挡。

### 6.2 试验仪器

#### 6.2.1 亮度计

亮度计的计量性能应符合 JJG 211—2005 规定的一级要求。

#### 6.2.2 电能质量分析仪

电能质量分析仪能耗测试值的最大允许示值误差为 ±2%。

### 6.3 试验方法

#### 6.3.1 公路隧道照明系统处于正常工作状态下,在白天不同时刻测试隧道洞外亮度、各照明段路面亮度平均值、路面亮度总均匀度和路面亮度纵向均匀度等指标,测试按附录 A 的规定进行,每个时刻的测试结果为 1 组数据,测试数据不少于 3 组。

#### 6.3.2 根据实际测试的隧道洞外亮度,计算得到相应时刻公路隧道各照明段的路面亮度平均值、路面亮度总均匀度、路面亮度纵向均匀度等技术指标,将计算结果与亮度计测试结果进行对比,测试结果均应不小于计算结果。

### 6.4 能效计算

根据公路隧道照明设计文件,按照式(1)计算得到公路隧道照明系统单位时间(24 h)照明能耗参考值。

$$
Q = \sum \alpha_ {i} \times L _ {i} \times l _ {i}\tag{……(1}
$$

式中:

$Q$ ———根据公式计算的隧道照明系统单位时间 的照明能耗参考值 单位为千瓦时 $( \mathrm { k W \cdot h } )$ ;

$\alpha _ { i }$ ———某一隧道照明段单位长度 单位路面亮度的能耗系数 单位为千瓦时 平方米每米 坎德拉$[ ( \mathrm { \bf ~ k W } \cdot \mathrm { \bf ~ h ~ } \cdot \mathrm { \bf ~ m } ^ { 2 } ) / ( \mathrm { \bf ~ m } \cdot \mathrm { \bf ~ c d } ) ]$ ,详见表 2;

$l _ { i }$ ———某一隧道照明段长度标准值,单位为米(m)；

### A.2 路面亮度

#### A.2.1 路面亮度测量按以下步骤进行:

a) 测试区域纵向的起点和终点宜选择同侧基本照明灯具所在位置对应的隧道横断面,纵向范围距离宜为 100 m,不足 100 m 时应选择被测试照明段内不包括第一组和最后一组灯具的照明区域作为纵向测试区域;

<!-- 第 4 页 -->

b) 在测试区域纵向,应按间距不大于3 m 的原则等间距布置测点;

c) 在测试区域横向,每条车道内应至少布置3 个测点,中间的测点应位于车道的中心线上,两侧的测点应分别位于距车道两侧边界线1/6 车道宽处;

d) 亮度计观测点的高度应距路面 1. 5 m,亮度计观测点的纵向位置应距第一排测量点为 60 m;

亮度计观测点的横向位置 对于平均亮度和亮度总均匀度的测量 应位于观测方向右侧路缘内侧四分之一路宽处,对于亮度纵向均匀度的测量,应位于每条车道的中心线上。

#### A.2.2 路面亮度平均值按照式(A.1)计算:

$$
L _ {\mathrm{av}} = \frac {\sum_ {i = 1} ^ {n} L _ {i}}{n}\tag{……(A.1}
$$

式中:

$L _ { \mathrm { a v } }$ ———平均亮度,单位为坎德拉每平方米 $( \mathrm { c d } / \mathrm { m } ^ { 2 } )$ ;

$L _ { i }$ ———各测点的亮度 单位为坎德拉每平方米 $( \mathrm { c d } / \mathrm { m } ^ { 2 } )$ ;

$n$ ———测点数, $i = 1 , 2 , 3 , \cdots , n$ ；

#### A.2.3 路面亮度总均匀度按照式(A.2)计算:

$$
U _ {0} = \frac {L _ {\min}}{L _ {\mathrm{av}}}\tag{……(A.2}
$$

式中:

$U _ { 0 }$ ———亮度总均匀度;

$L _ { \mathrm { m i n } }$ ———从规则分布测点上测出的最小亮度,单位为坎德拉每平方米 $( \mathrm { { c d } / \mathrm { { m } } ^ { 2 } ) }$ ；

#### A.2.4 路面亮度纵向均匀度按照式(A.3)计算:

$$
U _ {\mathrm{L}} = \min \left(\frac {L _ {\min} ^ {\prime}}{L _ {\max} ^ {\prime}}\right)\tag{……(A.3}
$$

式中:

$U _ { \mathrm { L } }$ ———亮度纵向均匀度 取各车道路面亮度纵向均匀度的最小值

$L _ { \mathrm { m i n } } ^ { \prime }$ ———分别测出的每条车道中线的最小亮度 单位为坎德拉每平方米 $( \mathrm { c d } / \mathrm { m } ^ { 2 } )$ ;

$L _ { \mathrm { m a x } } ^ { \prime }$ ———分别测出的每条车道中线的最大亮度,单位为坎德拉每平方米 $( \mathrm { c d } / \mathrm { m } ^ { 2 } )$ ；

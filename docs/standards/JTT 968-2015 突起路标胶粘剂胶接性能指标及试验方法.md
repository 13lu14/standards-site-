 突起路标胶粘剂胶接性能指标及试验方法

## 1 范围

本标准规定了突起路标胶粘剂的胶接性能技术指标和试验方法。

本标准适用于公路沥青路面、混凝土路面安装突起路标胶粘剂，其他道路路面安装突起路标胶粘剂可参照使用。

### 3. 6

## 搭接接头 lap joint

被粘物主表面部分地重叠、胶接在一起所形成的接头。

[GB / T 2943—2008，定义 7. 7]

### 3. 7

## 对接接头 butt joint

被胶接的两个端面或一个断面与被粘物主表面垂直的接头。

[GB / T 2943—2008，定义 7. 8]

### 3. 8

## 剪切强度 shear strength

在平行于胶层的荷载作用下，胶接试样破坏时，单位胶接面所承受的剪切力。 用兆帕(MPa)表示。

### 3. 9

## 拉伸强度 tensile strength

在垂直于胶层的荷载作用下，胶接试样破坏时，单位胶接面所承受的拉伸力。 用兆帕(MPa)表示。

### 3. 10

## 抗压强度 compressive strength

在垂直于胶层的荷载作用下，胶接试样破坏时，单位胶接面所承受的压缩力。 用兆帕(MPa)表示。

### 3. 11

## 压缩剪切强度 compressive shear strength

在平行于胶接界面层的轴向的压缩荷载作用下，使胶粘剂胶接接头破坏的应力。 用兆帕(MPa)表示。

### 3. 12

## 粘附破坏 adhesive failure；adhesion failure

胶粘剂和被粘物界面处发现的目视可见的破坏现象。

[GB / T 2943—2008，定义 2. 4]

### 3. 13

## 内聚破坏 cohesive failure；cohesion failure

胶粘剂和被粘物中发现的目视可见的破坏现象。

[GB / T 2943—2008，定义 2. 5]

## 5 试验方法

### 5. 1 试验环境

试验的温湿度应符合GB/T 12954.1—2008 的规定。 标准环境：温度 $( 2 3 \pm 2 ) ^ { \circ } \mathrm { C }$ ，相对湿度(50 ± 5)% 。

### 5. 2 胶粘剂取样

胶粘剂取样按 GB/T 20740 的要求进行。

### 5.3 胶粘剂调节

胶粘剂状态调节应符合 GB/T 9278 的规定。

### 5.4 压缩剪切强度

#### 5.4.1 混凝土块制备

试验用混凝土块应采用强度等级不低于 C30 的混凝土，制备三块 $5 0 \mathrm { m m } \times 1 0 0 \mathrm { m m } \times 2 0 0 \mathrm { m m }$ 的混凝土块。 在标准条件下养护不少于 28d 后备用，其胶接面的表面平整度要求 100mm 不大于 0. 5mm。

#### 5. 4. 2 胶接件制备

将三块混凝土块以搭接接头方式胶接成一个胶接件，胶接件的形式和尺寸如图1 所示。 单侧胶接面积为 $1 0 0 \mathrm { { m m } \times 1 0 0 \mathrm { { m m } } }$ 。 制备胶接件三个，在标准试验环境下放置 $2 4 \mathrm { h } _ { \mathrm { ~ c ~ } }$ 胶粘剂按厂家推荐的方法和用量使用。

#### 5.4.3 压缩剪切强度试验

##### 5. 4. 3. 1 压缩剪切强度(标准状态)

压缩剪切方向如图 所示 按 方法制备的胶接件置于精度不低于 级的电子万能试验机球形支座的基板上，调整胶接件位置和球形支座，使胶接件与压片的中心线在同一垂线上，并使胶接件顶面与加压面保持平行。

启动试验机，设定试验机预负荷为 10N，以适当速度达到预负荷后，开始记录试验机压头位移，以30mm/min 的速度加载，直至胶接件破坏为止，记录胶接件破坏的最大荷载和破坏类型。

按式(1)计算压缩剪切强度：

$$
\tau = \frac {P}{A}\tag{1}
$$

式中： $: \tau \cdot$ ———压缩剪切强度，单位为兆帕(MPa)；

P———胶接件破坏的最大荷载，单位为牛(N)；

A———中间混凝土块两侧胶接总面积，单位为平方毫米 $\left( \mathbf { m m } ^ { 2 } \right)$ 。

试验后取其平均值。

##### 5. 4. 3. 2 压缩剪切强度(浸水状态)

按 5. 4. 2 方法制备的胶接件浸入温度为(23 ± 2)℃ 的蒸馏水中，7d 后取出，立即按 5. 4. 3. 1 的方法测试胶接件压缩剪切强度(浸水状态)。

### 5. 5 拉伸强度

按 中第 章规定的方法进行 采用对接接头方式制备钢 钢胶接件三个 在标准试验环境下放置 后 测试胶接件拉伸强度 记录胶接件破坏的最大荷载和破坏类型 试验后取其平均值。

### 5.6 抗压强度

按 JT/T 280—2004 中6.4.7 规定的方法进行。 制备胶粘剂浇铸试块三个，在标准试验环境下放置24h 后，测试胶粘剂浇铸试块抗压强度，试验后取其平均值。

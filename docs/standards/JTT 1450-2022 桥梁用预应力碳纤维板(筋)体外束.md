## 3 术语和定义

下列术语和定义适用于本文件。

<!-- 第 1 页 -->

### 3.1 预应力碳纤维板(筋)体外束 external prestressing CFRP system

位于桥梁结构体外,由碳纤维板(筋)、锚固装置组成的预应力束。

### 3.2 碳纤维板(筋) carbon fiber plate or bar

碳纤维丝束采用环氧树脂浸渍黏结,通过拉挤复合工艺成型,用于结构补强加固的单向纤维薄板或矩形方条。

### 3.3 楔形锚具 wedge-shaped anchor

由楔形夹片、锚环、结构胶组成,用于夹持张拉、锚固碳纤维板(筋)的锚固装置。

### 3.4 平板锚具 flat-shaped anchor

由金属平板、螺栓、结构胶组成,用于施加应力后的碳纤维板与构件压紧黏结的锚固装置。

## 4 分类、结构形式、规格和型号

### 4.1 分类

#### 4.1.1 按碳纤维板(筋)束体宽厚比分为:

a) 宽厚比大于10 的预应力碳纤维板体外束,代号:P;

b) 宽厚比小于或等于10 的预应力碳纤维筋体外束,代号:B。

#### 4.1.2 按锚具形式分为:

a) 楔形锚具体外束,代号: $\mathbf { \Psi } : \mathbb { W }Ψ$ ;

b) 平板锚具体外束,代号: $\mathrm { \Delta } \cdot \mathrm { F _ { \circ } }$

#### 4.1.3 按张拉方式分为:

a) 单螺杆张拉体外束,代号:S;

b) 双螺杆张拉体外束,代号:D。

#### 4.1.4 按黏结方式分为:

a) 有黏结预应力碳纤维板(筋)体外束,代号:H;

b) 无黏结预应力碳纤维板(筋)体外束,代号:N。

### 4.2 结构形式

#### 4.2.1 预应力碳纤维板楔形锚具体外束由碳纤维板、楔形锚具和张拉装置（包括牵引螺杆、锁固螺母、张拉端支承、固定端支承）及碳纤维复合板材胶、胶锚螺栓等组成。张拉牵引分为单螺杆和双螺杆，单螺杆结构示意见图1，双螺杆结构示意见图2。

#### 4.2.2 预应力碳纤维板平板锚具体外束由碳纤维板、平板锚具、碳纤维复合板材胶、胶锚螺栓、工具锚和临时张拉装置（包括牵引螺杆、张拉端支承、固定端支承、导轨压板）等组成。结构示意见图3。

#### 4.2.3 预应力碳纤维筋楔形锚具体外束由碳纤维筋、碳纤维复合板材胶、楔形锚具和张拉装置（包括牵引螺杆、锁固螺母、张拉端螺母卡座、固定端螺母卡座、张拉端底板、固定端底板）及胶锚螺栓等组成。预应力碳纤维筋体外束分为有黏结和无黏结构造，有黏结结构示意见图4，无黏结结构示意见图5。

## 5 技术要求

### 5.1 外观与尺寸

#### 5.1.1 碳纤维板(筋)表面应符合 GB/T 21490 的规定。

#### 5.1.2 锚具不应有破损、裂纹、机械损伤等缺陷,裸露表面应采用防腐处理。

#### 5.1.3 张拉装置外露表面涂层应完好无损,不应有破损、裂纹、机械损伤等缺陷。

#### 5.1.4 碳纤维复合板材胶外包装应完好无损,胶液不应有分层、结晶等现象。

#### 5.1.5 未注公差尺寸的公差等级,应符合 GB/T 1804 中 C 级的规定。

#### 5.1.6 螺纹副未注精度等级,应符合 GB/T 197 中 7H/8g 的规定。

#### 5.1.7 机械加工应符合 JB/T 5000. 9 的规定。

#### 5.1.8 碳纤维板(筋)尺寸偏差应符合 GB/T 21490 的规定。

#### 5.1.9 碳纤维板(筋)形状公差直线度应不大于0.001。

### 5.2 材料

#### 5.2.1 碳纤维应采用 GQ4522 聚丙烯腈基碳纤维,其性能应符合 GB/T 26752 的规定。

#### 5.2.2 碳纤维复合树脂 应采用双酚 A 型环氧树脂,其性能应符合 GB/T 13657 的规定。

#### 5.2.3 钢材

5.2.3.1 锚环、夹片、螺母卡座、底板和平板锚,采用 Q355 低合金高强度结构钢,化学成分和力学性能应符合 GB/T 1591 的规定。
5.2.3.2 碳纤维板用张拉锚固装置的两端支承采用焊接结构件时,采用 Q235 碳素结构钢,化学成分和力学性能应符合 GB/T 700 的规定。

#### 5.2.4 铸钢锚环采用铸钢件时,选用 ZG310-570 铸钢,化学成分和力学性能应符合 GB/T 11352 的规定。

#### 5.2.5 球墨铸铁

5.2.5.1 锚环采用铸件时,选用 QT500-7 球墨铸铁,化学成分和力学性能应符合 GB/T 1348 的规定。
5.2.5.2 张拉锚固装置两端支承采用铸件时,选用 QT400-10 球墨铸铁,化学成分和力学性能应符合GB/T 1348 的规定。

#### 5.2.6 铝合金平板锚具采用7075 铝镁合金,化学成分和力学性能应符合 GB/T 3880.1 的规定。

#### 5.2.7 螺杆牵引螺杆应采用强度等级 10. 9 级的螺杆,化学成分和力学性能应符合 GB / T 3098. 1 的规定。

#### 5.4.3 预应力碳纤维板(筋)体外束

5.4.3.1 静载锚固性能 5.4.3.1.1 楔形锚具体外束静载锚固性能应满足下列要求:
楔形锚具体外束在静载锚固试验台进行张拉试验,静载锚固效率系数 $\eta _ { \mathrm { a } } \geqslant 0.8$, $\eta$ 按公式(1)计算;

$$
\eta_ {\mathrm{a}} = \frac {f _ {\mathrm{c}}}{f _ {\mathrm{b}}}\tag{1}
$$

式中:

$f _ { \mathrm { c } }$ ———预应力碳纤维板(筋)体外束出厂检验拉应力,单位为兆帕(MPa);

$f _ { \mathrm { b } }$ ———预应力碳纤维板(筋)标准拉应力,单位为兆帕(MPa)；

b) 楔形锚具体外束在静载锚固试验台上进行破坏性试验,其破裂实测极限拉应力 $( f _ { \mathrm { s } } )$ 应满足$f _ { \mathrm { s } } { \geqslant } 0 . 8 5 f _ { \mathrm { b } }$ ,预应力碳纤维板(筋)体外束总应变 $\left( \varepsilon _ { \mathrm { s } } \right)$ 应满足 $\varepsilon _ { \mathrm { { s } } } \geqslant 1$ . 45% 。

5.4.3.1.2 平板锚具体外束静载锚固性能(工具锚)应满足下列要求:

<!-- 第 9 页 -->

a) 平板锚具体外束在静载锚固试验台进行张拉试验,静载锚固系数 $\eta _ { \mathrm { a } } { \geqslant } 0 . 6 5 , \eta _ { \mathrm { a } }$ 按公式(1)计算;

b) 平板锚具体外束在静载锚固试验台上进行破坏性试验,其破裂实测极限拉应力 $( f _ { \mathrm { s } } )$ 应满足$f _ { \mathrm { s } } { \geqslant } 0 . 6 5 f _ { \mathrm { b } }$ ,预应力碳纤维板体外束总应变 $\left( \varepsilon _ { \mathrm { s } } \right)$ 应满足 $\varepsilon _ { \mathrm { s } } \geqslant 1 . 0 \%$ 。

注:平板锚具体外束 在静载锚固试验台上实施张拉试验 加载时使用的是可重复匹配的工具锚 破坏性试验是工具锚加载至碳纤维板标准拉应力 $f _ { \mathrm { b } }$ 的 $65 \%$ ,刮抹碳纤维板材胶螺栓压紧平板锚,胶体固化期满工具锚卸载后进行试验。

5.4.3.1.3 静载试验破坏形式:a) 张拉试验,不应出现预应力碳纤维板(筋)的局部破裂或断裂、锚具变形、夹持失效或张拉装置变形现象;

b) 破坏性试验,应是预应力碳纤维板(筋)的非夹持段首先发生局部破裂或断裂,不应是由于锚具变形导致预应力碳纤维板(筋)的夹持段产生破裂脱落,或因张拉装置变形而导致试验中止。

5.4.3.2 疲劳荷载性能预应力碳纤维板(筋)体外束经受200 万次循环疲劳荷载,应满足下列要求:
a) 试验应力值上限取预应力碳纤维板(筋)的抗拉强度标准拉应力 $f _ { \mathrm { b } }$ 的65%,应力幅值不小于80 $\mathrm { M P a }$ ;

b) 楔形锚具或平板锚具不应发生疲劳变形或破裂,张拉装置不应发生疲劳裂缝或变形;

c) 预应力碳纤维板(筋)因锚具夹持段发生疲劳破坏的面积不应大于试件筋材总面积的1%;

d) 应进行极限拉应力 $f _ { \mathrm { s } }$ 破坏性试验并满足
5.4.3.1 的要求。

5.4.3.3 应力松弛性能 预应力碳纤维板(筋)体外束应进行预应力长期应力松弛试验,应满足下列要求:
a) 试验值达到碳纤维板(筋)抗拉强度标准拉应力 $f _ { \mathrm { b } }$ 的 $65 \%$ 时,测量初始应变数值 $\left( \varepsilon _ { \mathrm { x } } \right)$ ,试验100 h 后测量终止应变数值 $\left( \varepsilon _ { \mathrm { d } } \right)$ ,应力松弛率 $r < 2 . 0 \%$ ,其数值按公式(2)计算:

$$
r = \left(1 - \varepsilon_ {\mathrm{d}} / \varepsilon_ {\mathrm{x}}\right) \times 100 \%\tag{2}
$$

b) 由100 h 松弛结果外推1 000 h 的应力松弛率,碳纤维板(筋)夹持长度 $L { \leqslant } 3 ~ 0 0 0 ~ \mathrm { m m }$ 时,松弛率 $\left( \boldsymbol { r } ^ { \prime } \right)$ 应满足 $r ^ { \prime } < 2$ .5%的要求。

## 6 试验方法

### 6.1 外观与尺寸

#### 6.1.1 外观质量检测采用目测或借助放大镜检测。

#### 6.1.2 碳纤维板(筋)外观检测应按 GB/T 21490 的规定进行。

#### 6.1.3 未注公差尺寸的公差等级检测应按 GB/T 1804 中 C 级的规定进行。

#### 6.1.4 螺纹副未注精度等级检测应按 GB/T 197 中 $7 \mathrm { H } / 8 \mathrm { g }$ 的规定进行。

#### 6.1.5 机械加工检测应按 JB/T 5000. 9 的规定进行。

#### 6.1.6 碳纤维板(筋)尺寸偏差检测应按 GB/T 21490 的规定进行。

#### 6.1.7 碳纤维板(筋)形状公差直线度试验应按附录 C 的规定进行。

### 6.2 材料

#### 6.2.1 碳纤维性能试验应按 GB/T 31290 的规定进行。

#### 6.2.2 碳纤维复合树脂性能试验应按 GB/T 13657 的规定进行。

#### 6.2.3 钢材性能试验应按 GB/T 1591 和 GB/T 700 的规定进行。

#### 6.2.4 铸钢性能试验应按 GB/T 11352 的规定进行。

#### 6.2.5 球墨铸铁性能试验应按 GB/T 1348 的规定进行。<!-- 第 10 页 -->

#### 6.2.6 铝合金性能试验应按 GB/T 3880. 1 的规定进行。

#### 6.2.7 螺杆性能试验应按 GB/T 3098. 1 的规定进行。

#### 6.2.8 螺母性能试验应按 GB/T 6187. 1 的规定进行。

#### 6.2.9 碳纤维复合板材胶性能试验应按 GB 50728 的规定进行。

#### 6.2.10 热收缩 PE 防护管性能试验应按 JB/T 11335 的规定进行。

### 6.3 工艺性能

#### 6.3.1 机械加工性能按 GB/T 1804、GB/T 197、JB/T 5000. 9 的规定进行。

#### 6.3.2 碳纤维板(筋)外形尺寸检验按 GB/T 21490 的规定进行。

#### 6.3.3 碳纤维复合板材胶混合后初黏度、触变指数按 GB 50550 的规定进行,25 ℃下垂流度按 GB/T 13477.6 的规定进行,各季节试验温度下测定的适用期按 GB/T 7123.1 的规定进行。金属零部件外表面防腐及防护质量检验应按 GB/T 1720、GB/T 15519 的规定进行。

### 6.4 力学性能

#### 6.4.1 预应力的碳纤维板(筋)力学性能和耐候性能试验应按 GB 50728 的规定进行。

#### 6.4.2 预应力碳纤维锚具锚固性能试验应按 GB/T 14370 的规定进行。楔形锚具静载锚固性能试验应按 GB/T 14370 的规定进行;平板锚具匹配的工具锚静载锚固性能试验应按 GB/T 14370 的规定进行;平板锚具静载锚固性能试验应在钢筋混凝土梁上,按5.4.3.1 的规定进行。

#### 6.4.3 预应力碳纤维板(筋)体外束静载锚固性能试验按附录 D 的规定进行

#### 6.4.4 预应力碳纤维板(筋)体外束疲劳荷载性能试验按附录 E 的规定进行

#### 6.4.5 预应力碳纤维板(筋)体外束应力松弛性能试验按附录 F 的规定进行

b) 预应力碳纤维板(筋)和锚具的力学性能采取二次抽样法,每组批随机抽取5 个样本。

### 7.3 判定原则每个项目均以全部样品合格判定为合格产品。 若有一项不合格,应双倍抽样重新检验,若仍不合格,则判定为不合格产品。

## 附 录 B

## (资料性)预应力碳纤维板(筋)体外束安装张拉要求

### B.1 安装

#### B.1.1 预应力碳纤维板(筋)体外束安装前应检查各组件的制造质量,应满足设计图技术要求。

#### B.1.2 预应力碳纤维板(筋)体外束与桥梁结构锚固连接螺栓强度等级应不小于8.8,采用钢筋探测仪放线钻孔,植入锚固结构胶宜使用环氧类植筋胶,不宜使用玻璃管不饱和类锚固胶。

#### B.1.3 预应力碳纤维板(筋)体外束两端支承与桥梁结构锚固时,优选采用嵌入式安装方式,当混凝土结构钢筋保护层厚度不满足嵌入式安装方式时,两端支承底板与混凝土结构层及底板锚固螺栓过孔,采用环氧结构胶黏结和填塞。

#### B.1.4 预应力碳纤维板(筋)体外束两端锚具安装后的中心线同轴线误差,应控制在设计规定的范围内,无设计要求的,其安装后的中心线同轴线允许偏差为±5 mm,角度允许偏差不大于0.1°。

#### B.1.5 预应力碳纤维板(筋)与混凝土结构黏结面,采用金刚石磨轮打磨并使用环氧结构胶修补,黏结面全长段平直度偏差不大于5 mm。

#### B.1.6 预应力碳纤维板(筋)体外束在安装过程中,应防止碳纤维板(筋)受到机械损伤、扭曲变形、压剪弯折等现象。

#### B.1.7 体外束应保持平直状态受力,不宜采用压板或外物弯折预应力碳纤维板(筋)。

#### B.1.8 安装两端平板锚具时,符合下列要求:

a) 碳纤维板全长段采用碳纤维板材胶黏结,黏结有效面积不小于95%;

b) 碳纤维板受拉长度不大于 20 m 时,两端各设置一套平板锚具;碳纤维板受拉长度大于 20 m时,两端各设置两套平板锚具,每端两套平板锚具安装间距不大于2 m;

c) 工具锚卸载拆除应在碳纤维板材胶常规固化后实施,碳纤维板分离切割线宜在平板锚具外侧的30 mm,并做好回缩观察检测标记。

#### B.1.9 安装结束后应提交体外束各组件的外观与尺寸和各阶段安装质量检查验收记录。

### B.2 张拉

#### B.2.1 预应力碳纤维板(筋)体外束张拉顺序应符合设计要求，设计无要求时，宜采取分批对称成组单端方式张拉。

#### B.2.2 预应力碳纤维板(筋)体外束张拉控制应力不应小于0.35f_k且不应大于0.55f_k，张拉时应采用应力和伸长量双控制。当采取分批对称成组张拉时，同一构件上每束预应力碳纤维板(筋)体外束的张拉应力偏差控制在±2.5%范围内。

#### B.2.3 预应力碳纤维板(筋)体外束应按张拉控制应力10%分级张拉，张拉控制应力增长速度不宜大于10 MPa/min。当采用超张法减少体外束预应力的锚固损失时，应从压力值为0开始计量张拉控制应力，至1.03倍预应力碳纤维板(筋)体外束张拉控制应力 $( \sigma _ { \mathrm { c o n } } )$ 后即刻锁固螺栓、螺母。

#### B.2.4 张拉过程中出现两端支承位移或变形、锚具夹持失效、预应力碳纤维板(筋)局部破裂等现象时，应立即停止张拉。两端支承胶锚螺栓锚固区混凝土出现锥形受拉破坏或剪撬破坏时，应沿纤维受力方向位移重新钻植胶锚螺栓；碳纤维板(筋)局部发生破裂时，应重新更换安装新的碳纤维板(筋)。

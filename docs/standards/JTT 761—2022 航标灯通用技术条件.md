## 3 术语和定义

GB/T 17765 所界定的以及下列术语和定义适用于本文件。

### 3.1 灯光射程 luminous range

由灯光的发光强度、大气透射率、灯光的背景条件和观察者眼睛的照度阈值四个因素所决定的灯光最大可见距离。

[来源:GB/T 17765—2021,3. 1. 14]

### 3.2 标称灯光射程 nominal range

在水平能见度为10 n mile 的均匀大气环境条件下的灯光射程。

注:水平能见度为10 n mile 相当于大气透射率为0.74。

[来源:GB/T 17765—2021,3. 1. 15]

### 3.3 节奏光的有效光强 effective intensity of rhythmic light

在同样环境和探测设备条件下,定光光源和节奏光光源两者的发光强度相等时的定光光源的发光强度。

[来源:GB/T 17765—2021,3. 1. 19]

### 3.4 灯光节奏 rhythm of light

灯光周期性明暗变化的规律。

[来源:GB/T 17765—2021,3. 5. 2]

### 3.5 节奏光周期 period of a rhythmic light

航标灯节奏光自开始到以同样的节奏重复时所经历的时间间隔。

### 3.6 笔形光束 pencil beam

集中在某一直线方向周围发射出去的光束。

### 3.7 扇形光束 fan beam

集中在一个面内或接近在一个面内发射的呈扇形的光束。

### 3.8 基准轴 reference axis

笔形光束所集中的直线。

注:基准轴通常参考制造商的使用说明或常用方式来确定。

### 3.9 基准面 reference plane

扇形光束所集中的面。

注1:这个面一般为水平面,某些情况下为锥面。

注2:基准面通常参考制造商的使用说明或常用方式来确定。

### 3.10 水平配光均匀度 uniformity of horizontal light distribution

航标灯基准面内最小发光强度与最大发光强度的百分比。

### 3.11 光束发散角 beam divergence angle

在同一平面内,在基准轴或基准面两侧,光强降为基准轴或基准面上光强50%的相对应光线与基准轴或基准面形成的两个夹角中较小者的2 倍。

### 3.12 垂直发散角 vertical divergence angle

垂直方向的光束发散角。

### 3.13 水平发散角 horizontal divergence angle

水平方向的光束发散角。

### 3.14 闪烁频率 flicker frequency

航标灯在定光发光状态下,单位时间内光度信号周期性变化的次数。

### 3.15 电源一体化航标灯 integrated power system lantern

集供电系统(包括发电装置、蓄电装置和电源管理装置等)于一体的航标灯。

## 4 技术要求

### 4.1 一般要求

#### 4.1.1 型号命名

航标灯的型号应包含厂商标识、灯器形式、特征尺寸、灯光颜色、集成化标识、同步闪光标识以及版本号,同一形式航标灯的软件或硬件设计发生变化时,版本号应做相应变更。命名方法见附录A。

#### 4.1.2 外观

航标灯的外观符合以下要求:

a) 所有构件不应有明显的凹痕、划伤、裂缝、变形和污染等,金属零部件不应有锈蚀;

b) 表面涂镀层应均匀,不应起泡、龟裂、划伤、脱落和磨损;

c) 紧固件应无松动;

d) 透镜应清洁、透明,不应有杂质、划痕和污物。

#### 4.1.3 零部件

航标灯的零部件应满足以下要求:

a) 同一型号航标灯的零部件通用、可互换,控制软件向下兼容;

<!-- 第 3 页 -->

b) 系列化航标灯遵循标准化、模块化和向上兼容的原则,并符合国家相关标准;

c) 透镜直径小于300 mm 采用螺栓固定的航标灯,在其底座的 Φ200 节圆上布设 4 个以上 Φ16的安装孔;

d) 具有防爆要求的航标灯,零部件性能符合 GB 3836.1 的规定。

#### 4.1.4 防腐蚀涂镀

航标灯零部件除用耐腐蚀材料制造及按结构原理不需要涂镀的以外,所有金属表面均应涂或镀有耐腐蚀保护层。

#### 4.1.5 材料

航标灯的制造材料符合以下要求:

a) 透光材料应为抗紫外线材料,按 5.2.3 a) 的方法试验后,不应出现起雾、变色(变黄)、龟裂等现象;

b) 零部件应为抗老化材料,按 5. 2. 3 b)的方法试验后,不应出现粉化、褪色、开裂等现象;

c) 电路组件应采用工业级或更优的元器件,表面涂覆防潮、盐雾、霉菌的“三防”涂层;

d) 电源电缆应采用橡胶绝缘船用电缆和铜质导线;

e) 具有防爆要求的航标灯,材料的性能应符合 GB 3836.1 的规定。

#### 4.1.6 寿命

航标灯光源及电源一体化航标灯蓄电池的寿命满足以下要求:

a) 在额定工作电压下,气体放电型光源的平均寿命不应小于6 000 h;LED 光源的寿命不应小于50 000 h,在寿命期限内,其光输出不应低于初始值的70%。

b) 电源一体化航标灯蓄电池的循环寿命不应低于500 次,按 5.2.4 方法进行循环寿命试验,循环 500 次后放电容量不应低于额定容量的 80%。可独立更换蓄电池的航标灯,更换蓄电池的累计寿命应满足此要求。

#### 4.1.7 使用说明书

航标灯的使用说明书应符合 GB/T 9969 的规定,内容至少应包括安全注意事项、技术特性、结构与工作原理、安装指南、操作规程、维护保养规则、灯质表等,具有信息传输功能的航标灯还应包括通信协议。

### 4.2 产品性能

#### 4.2.1 灯质

4.2.1.1 航标灯灯质应符合 GB 4696 和 GB 5863 的规定。
4.2.1.2 实测节奏光的各节明暗时间与规定值的偏差不应超过 ±2%。

#### 4.2.2 发光强度和射程

航标灯的发光强度和射程满足以下要求:

a) 定光发光的航标灯应按定光光强标称射程;节奏光发光的航标灯应按节奏光的有效光强标称射程。

b) 航标灯发光强度的实测值不应小于标称灯光射程对应的发光强度。

#### 4.2.3 灯光颜色

航标灯的灯光颜色应符合 GB 12708 的规定。

#### 4.2.4 节奏光周期误差

航标灯节奏光周期误差不应超过 ±1%。

#### 4.2.5 水平配光均匀度

如无特殊规定,航标灯的水平配光均匀度不应小于70%。

#### 4.2.7 日光开关照度阈值

航标灯日光开关的开启照度阈值应在50 lx \~400 lx 范围内可调,关闭照度阈值应高于开启照度阈值 100 lx \~ 150 lx。 如无特殊规定,出厂时,开启照度阈值宜设为 300 lx ± 50 lx。

#### 4.2.8 耗电功率

4.2.8.1 航标灯应标称满功率发光时的耗电功率,航标灯集成的其他耗电模块的耗电功率应单独标称。

4.2.8.2 航标灯实测耗电功率不应大于标称耗电功率的110%。

#### 4.2.9 闪烁频率

航标灯光源的闪烁频率不应小于 100 Hz。

#### 4.2.10 旋转速度和误差

旋转式航标灯的旋转速度应在0.5 r/min \~10 r/min 范围内可调,旋转速度误差不应大于 ±2%。

#### 4.2.11 信息传输

航标灯的信息传输内容应满足 JT/T 788 的规定。

#### 4.2.12 同步闪光

航标灯的同步闪光应采用卫星授时时钟,应以 UTC 时间0 h 0 min 0 s 为计算同步点的时间起点。<!-- 第 5 页 -->

### 4.3 电源适应性

#### 4.3.1 交流电源

交流电源供电的航标灯,电源额定值应为 AC 220 V/50 Hz。 当电源电压变化 ±15%、频率变化 ±5%时,航标灯应能正常工作。 各状态下发光强度的变化与额定状态相比均不超过 ±5%。

#### 4.3.2 直流电源

直流电源供电的航标灯,电源额定范围宜在 DC 3 V ~36 V 之间。使用说明书中应标称电源电压的范围或额定值。在标称的电源电压范围内或额定电压变化 ± 20% 时,航标灯应能正常工作,且发光强度与额定状态相比,变化均不应超过 ±5%。

#### 4.3.3 电源一体化航标灯电源

电源一体化航标灯的电源系统满足以下要求:

a) 稳定性:应保证航标灯在额定工作状态下发光强度变化不应超过 ±5%。

b) 发电单元满足以下要求:

1) 转换效率:太阳能电池组件宜采用高效率组件,转换效率应符合设计规范,单晶硅太阳能电池组件应大于 17%,多晶硅太阳能电池组件应大于 16%,非晶硅太阳能电池组件应大于 8%。

2) 发电能力:在温度为25 ℃、辐射照度为 $1 0 0 0 \ \mathrm { W / m } ^ { 2 }$ 的条件下,太阳能电池组件5 h 的发电量应至少为航标灯明暗占空比为 1:1 的节奏光日耗电量的 2 倍。

c) 储能容量:如无特殊规定,储能单元的容量不应低于航标灯明暗占空比为 1:1 的节奏光日耗电量的15 倍。

### 4.5 环境适应性

#### 4.5.1 高温

航标灯在最高环境温度为 60 ℃时应能正常工作。

#### 4.5.2 低温

航标灯在最低环境温度为 -35 ℃时应能正常工作。

#### 4.5.3 湿热

航标灯在55 ℃的湿热环境下应能正常工作,绝缘电阻应符合表 2 的规定,外观应符合 4. 1. 2 的要求。

#### 4.5.4 摇摆

用于浮动助航标志的航标灯按 GB/T 2423.101 规定的最严酷等级进行首摇、纵摇和横摇以及纵荡、横荡和垂荡等摇摆试验,试验后应能正常工作,且无机械损伤,接触不良和紧固件松动等现象。

#### 4.5.5 振动

航标灯应能承受频率范围为 $1 0 ~ \mathrm { H z } \sim 1 5 0 ~ \mathrm { H z }$ 、最大加速度为 $2 0 ~ \mathrm { m / s } ^ { 2 }$ 的三个相互垂直方向的振动试验,试验后应能正常工作,且无机械损伤,接触不良和紧固件松动等现象。

#### 4.5.6 冲击

用于浮动助航标志的航标灯应能承受峰值加速度为 $5 0 0 ~ \mathrm { m / s } ^ { 2 }$ 的三个相互垂直方向的冲击试验,其他航标灯应能承受峰值加速度为 $3 0 0 ~ \mathrm { m / s } ^ { 2 }$ 的三个相互垂直方向的冲击试验,试验后应能正常工作,且无机械损伤,接触不良和紧固件松动等现象。

#### 4.5.7 碰撞

航标灯应能承受峰值加速度为 $2 5 0 \ \mathrm { m / s } ^ { 2 }$ 的三个相互垂直方向的碰撞试验,试验后应能正常工作,且无机械损伤,接触不良和紧固件松动等现象。

#### 4.5.8 盐雾

海上应用的航标灯应按 GB/T 2423.18—2021 规定的严酷等级(1)进行耐盐雾试验,试验后应能正常工作,外观变化应无腐蚀、质变现象。对内河应用的航标灯不做此项要求。

#### 4.5.9 外壳防护

4.5.9.1 室外工作航标灯的外壳防护等级,应同时满足 GB/ T 4208—2017 规定的 IP 66 和 $\mathrm { I P } 6 7$ 的要求。

4.5.9.2 室内工作航标灯的外壳防护等级,按其工作条件确定。

1) 采用气体放电型光源的航标灯,其光源寿命按照 GB/T 18661 规定的方法进行试验;

3) 重复 1) \~2)充放电过程,连续循环 500 次。

### 5.3 产品性能

#### 5.3.1 灯质试验

任意指定至少五种节奏光灯质,采用光电探测器以不小于 500 Hz 的采样频率测量灯光节奏。

a) 按以下方法确定测量位置:

1) 笔形光束航标灯在基准轴上进行测量。

2) 扇形光束航标灯,在基准面的第十百分位发光强度点(见5.3.5)进行测量。

b) 按以下方法进行定光光强或节奏光有效光强的测量:

1) 定光光强,按 JT/T 730 规定的方法进行测量。

2) 节奏光的有效光强,对通过遮蔽或开关产生节奏光的航标灯,采用联闪2 次、周期6 s(即明 0.5 s、暗 1 s、明 0.5 s、暗 4 s)的灯光节奏;对通过旋转光学装置产生节奏光的航标灯,采用单闪,周期 12 s 的灯光节奏。采用光电探测器以不小于 500 Hz 的采样频率测量光强随时间的变化,按附录 B 规定的方法进行计算。

c) 射程计算:根据测得的发光强度,按 JT/T 730 规定的方法计算灯光射程。

#### 5.3.3 灯光颜色测量

在航标灯标称的光束发散角范围内,以最大程度分散的方式取3 个测量点,分别测量各点的光谱功率分布,并按 GB/T 3977 计算各点的 CIE 1931 色品坐标。

$$

式中:

$U$———水平配光均匀度;

$I _ { \mathrm { m i n } }$ ———最小发光强度,单位为坎德拉(cd);

#### 5.3.6 光束发散角测量

航标灯的光束发散角按以下步骤测量:

a) 按以下方法确定测量位置:

1) 笔形光束航标灯,在基准轴所在的水平面和垂直面上进行测量;

2) 扇形光束航标灯,至少选取 3 个垂直面进行测量,其中应包括基准面上的最大发光强度点、最小发光强度点和第十百分位发光强度点(见 5.3.5)所在的垂直面。

b) 测量过程:航标灯在定光状态下发光,按 JT/T 730 规定的方法,采用分度精度不低于 0.1°的分布光度计,以不大于 0.1°的角度间隔,在测量面上测量各点的发光强度。

c) 结果计算:对每个测量面,分别计算基准轴或基准面两侧,光强降为基准轴或基准面光强 50% 的光线与基准轴或基准面之间的夹角 $\alpha _ { 1 }$ 和 $\alpha _ { 2 }$ ,所测平面的光束发散角 $\alpha$ 为 $2 \times \operatorname* { m i n } { \{ \alpha _ { 1 } , \alpha _ { 2 } \} }$。其中,笔形光束航标灯在两个测量面上所测得的光束发散角直接记作水平发散角和垂直发散角。 扇形光束航标灯取各测量面光束发散角的平均值作为航标灯的垂直发散角。

1) 光源:实验室测量使用色温为4 500 K 的类太阳光光谱的漫照射标准光源;现场测量采用太阳光。

b) 按以下方法进行实验室测量或现场测量:

使航标灯在满功率工作状态下发光,按 GB/T 24824 规定的方法进行测量。航标灯内集成的其他耗电模块的耗电功率应单独测量。

#### 5.3.9 闪烁频率测量

使航标灯在定光状态下发光,采用光电探测器以不小于500 Hz 的采样频率进行测量。

#### 5.3.10 旋转速度和误差测量

5.3.10.1 在航标灯上设置辨认旋转的标记,采用精度不低于0.01 s 的计时装置进行测量。

5.3.10.2 任意设定五种转速使航标灯工作,其中应包含最低转速和最高转速。

5.3.10.3 对每种转速,测量旋转 5 周的时间,计算旋转速度及误差。

#### 5.3.11 信息传输测量

按 JT/T 788 规定的方法进行测量。

#### 5.3.12 同步闪光测量

在卫星授时时钟下测量航标灯的节奏光,计算其同步闪光时间起点。

### 5.4 电源适应性

#### 5.4.1 交流电源适应性测量

航标灯设置为定光状态,在 AC 220 V/50 Hz 交流电源供电下正常发光,按 JT/T 730 规定的方法监测发光强度,待发光强度稳定后,记下此时的稳定光强 $\left( { { I _ { 0 } } } \right)$ 。然后,按表4 规定调节电源的电压和频率,使航标灯在每个变化状态下各运行 10 min,记录各状态下的发光强度 $( I _ { i } )$ 。按公式(2)计算发光强度的变化率(ηi)。

$$
\eta_ {i} = \frac {I _ {i} - I _ {0}}{I _ {0}} \times 100 \%\tag{2}
$$

式中:

$\eta _ { i }$ ———发光强度的变化率;

$I _ { i }$ ———每个变化状态下的发光强度,单位为坎德拉(cd);

#### 5.4.3 电源一体化航标灯电源适应性测量

电源一体化航标灯电源适应性按以下方法进行测量:

a) 电源稳定性:航标灯在定光状态发光,按 JT/T 730 规定的方法监测发光强度,待发光强度稳定后,记下此时的稳定光强 $\left( I _ { 0 } \right)$ ,然后,每隔5 min 记录一次数据 $( I _ { i } )$ ,至少持续1 h。按公式(2)计算发光强度的变化率 $( \eta _ { i } )$ 。

b) 按以下方法测量发电单元的转换效率和发电能力:

1) 转换效率:按 GB/T 34160 规定的方法,在温度为25 ℃、辐射照度为 $1 0 0 0 \ \mathrm { W / m } ^ { 2 }$ 的条件下,测量太阳能电池板的最大功率 $P _ { \mathrm { { m a x } } }$ ,并根据太阳能电池板的总面积,计算转换效率。

2) 发电能力:按航标灯明暗占空比为1 ∶1 的节奏光每日发光14 h 计算航标灯的日耗电量,计算方法见公式(3)。

$$
Q _ {\mathrm{c}} = 7 P _ {\mathrm{c}}\tag{......3}
$$

(3)

式中:

$Q _ { \mathrm { c } }$ ———航标灯的日耗电量,单位为瓦小时(W·h);

$P _ { \mathrm { ~ c ~ } }$ ———航标灯的实测耗电功率,单位为瓦(W)。

3) 发电单元的日发电量按公式(4)计算。

$$
L = P _ {\max} \times R \times T\tag{......4}
$$

(4)

式中:

#### 5.6.1 高温试验

按 GB/T 2423. 2—2008 规定的”试验 $\mathrm { B d } ^ { \prime \prime }$ 的方法进行试验。 试验期间,对采用直流电源供电的航标灯以电压额定值的上限供电。 航标灯初始检测应工作正常。 试验严酷等级为 $6 0 \mathrm { ~ ℃ ~ }$ ±2 ℃,持续时间 2 h,恢复时间 2 h。试验期间,航标灯应通电工作。

#### 5.6.2 低温试验

按 GB/T 2423. 1—2008 规定的”试验 $\mathbf { A d } ^ { \prime \prime }$ 的方法进行试验。 试验期间,对采用直流电源供电的航标灯以额定值的下限供电。航标灯初始检测应工作正常。试验严酷等级为 -35 ℃ ± 3 ℃,持续时间 2 h,恢复时间 2 h。试验期间,航标灯应通电工作,或达到低温持续时间后保持低温状态通电工作 1 h。

#### 5.6.3 湿热试验

按 GB/T 2423.4 规定的方法进行试验。试验严酷程度为 55 ℃,循环次数为 1 次。初始检测外观和冷态绝缘电阻,航标灯应能正常工作。 在高温高湿阶段的前2 h 和低温高湿阶段最后2 h,航标灯通电应能正常工作。试验后在 GB/T 2421.1 规定的测量和试验用标准大气条件下进行恢复,在恢复的第2 个小时进行最后检查,检测外观、湿热态绝缘电阻,并能通电正常工作1 h。

## (规范性)航标灯节奏光的有效光强计算方法

航标灯节奏光的有效光强采用修正的阿拉德方法(Modified Allard Method, MAM)进行计算,节奏光的有效光强 $I _ { \mathrm { e } }$ 为节奏光光强函数与视觉响应函数卷积的最大值,其计算按公式(B.1)和公式(B.2)进行。

$$
I _ {\mathrm{e}} = \max _ {t} \left\{\int_ {- \infty} ^ {+ \infty} I (t - t ^ {\prime}) \cdot q (t ^ {\prime}) \mathrm{d} t ^ {\prime} \right\}\tag{B.1}
$$

式中:

$I(t)$———闪光在 t 时刻的瞬时发光强度;

$q ( t )$ ———视觉脉冲响应函数；

$$
q (t) = \left\{ \begin{array}{l l} \frac {a}{(a + t) ^ {2}} & t \geqslant 0 \\ 0 & t <   0 \end{array} \right.\tag{B.2}
$$

式中:

$a$ ———视觉时间常数,其中:夜间蓝光 $a = 0 . 2 \mathrm { ~ s ~ }$ ,夜间非蓝光 $a = 0$ . 1 s;

t ———时间,单位为秒(s)。

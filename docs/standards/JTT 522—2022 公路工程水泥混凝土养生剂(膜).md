## 前 言

本文件按照 GB/T 1.1—2020《标准化工作导则 第1 部分:标准化文件的结构和起草规则》的规定起草。

本文件代替 JT/T 522—2004《公路工程混凝土养护剂》,与 JT/T 522—2004 相比,除编辑性修改外,主要技术变化如下:

———更改了养生剂、基本型养生膜、吸水型养生膜的术语和定义(见2004 年版的第3 章);

———更改了养生剂(膜)产品的分类和代号(见第4 章,2004 年版的第4 章);

———增加了养生剂的含固量、弯拉强度比性能要求(见5.2.1);

———增加了基本型养生膜及养生水泥混凝土性能要求,增加厚度、长度允许偏差、宽度允许偏差、水蒸气透过量、一次性保水时间、弯拉强度比等性能要求(见5.2.2);

———增加了吸水型养生膜及养生水泥混凝土性能要求,增加厚度、长度允许偏差、宽度允许偏差、水蒸气透过量、一次性保水时间、单位面积吸蒸馏水量、弯拉强度比等性能要求(见5.2.3);

———删除了养生膜的密封性、浸水溶解性、耐热性要求(见2004 年版的6.6、6.7、6.8);

———增加了养生膜的外观、弯拉强度比、厚度、长度和宽度允许误差、24 h 水蒸气透过量、一次性保水时间、单位面积吸蒸馏水量性能试验方法(见6.2、6.10、6.12、6.13、6.14、6.15、6.16);

———更改了磨损量试验方法(见6.11,2004 年版的6.4);

———更改了检验项目(见第7 章,2004 年版的第7 章);

———更改了标志、包装、运输和储存(见第8 章,2004 年版的第8 章);

———更改了附录 B(见附录 B,2004 年版的附录 B);

———删除了附录 C(见2004 年版的附录 C)。

 公路工程水泥混凝土养生剂(膜)

## 1 范围

本文件规定了公路工程水泥混凝土养生剂(膜)的分类和标记的分类和代号、技术要求、试验方法、检验规则,以及标志、包装、运输和储存等要求。

本文件适用于公路工程水泥混凝土用养生剂和养生膜的生产、检验和使用。

## 3 术语和定义

下列术语和定义适用于本文件。

### 3.1 养生剂 curing compound

喷洒或者涂刷于水泥混凝土表面 可以形成一层连续的保水密闭养生膜的乳液或高分子溶液

### 3.2 基本型养生膜 curing sheet

覆盖于水泥混凝土表面 具有不透水性能的密封膜层材料

### 3.3 吸水型养生膜 water-absorption curing sheet

由吸水、释水材料和塑料膜构成的养生膜 具有蓄水、补水及不透水性能的密封膜层材料

## 4 分类和代号

### 4.1 养生剂公路工程水泥混凝土用养生剂按照性能指标分为Ⅰ型和Ⅱ型,代号为 YSJ。<!-- 第 1 页 -->

### 4.2 养生膜公路工程水泥混凝土用养生膜按照材料性能不同分为基本型养生膜和吸水型养生膜,代号分别为 YSM-J、YSM-X。 吸水型养生膜按照结构分为单层养生膜和双层养生膜,代号分别为 YSM-X-D 和YSM-X-S。

## 5 技术要求

### 5.1 外观

#### 5.1.1 养生剂应均匀、无明显色差,不含其他杂质。

#### 5.1.2 养生膜应干净、整齐、无破损,不起皱。

## 6 试验方法

### 6.1 试验原材料及配合比

#### 6.1.1 试验所用水泥、砂、石、水等材料应符合 GB 8076 的要求,养生剂的产品检验用原液的用量为 0. 2 $\mathbf { k g } / \mathbf { m } ^ { 2 }$ ,也可采用生产厂家的推荐用量。<!-- 第 3 页 -->

#### 6.1.2 试验用混凝土配合比应符合 JGJ 55 的要求 其中 水泥用量为 $3 3 0 ~ \mathrm { k g } / \mathrm { m } ^ { 3 }$ 混凝土的砂率满足用水量以混凝土坍落度控制在 $4 0 \ \mathrm { m m } \pm 1 0 \ \mathrm { m m }$ 为准。

### 6.2 外观目测养生剂(膜)的外观质量。

### 6.3 含固量按 GB / T 8077 的规定进行。

### 6.4 干燥时间养生剂干燥时间的试验方法按如下规定进行:

a) 水泥砂浆按 JC/T 421 的规定制备;

b) 按照试验规定的用量将养生剂喷涂于泌水结束后的水泥砂浆表面;

c) 将喷涂养生剂的试样置于温度为 $2 0 ^ { \circ } \mathrm { C } \pm 2 ^ { \circ } \mathrm { C }$ 、相对湿度为 $( 5 0 \pm 1 0 )$ %的条件下养护;

d) 从喷涂养生剂时开始计时,每20 min 一次,用手指轻轻触压表面,若表面不再粘手,则认为已干燥,记录此时的时间即为干燥时间。

### 6.5 成膜后浸水溶解性养生剂成膜后浸水溶解性的试验方法按如下规定进行

将养生剂按试验规定的用量涂于玻璃板上 涂覆面积不小于 $1 5 0 \ \mathrm { m m } \times 1 5 0 \ \mathrm { m m }$ ;

b) 放在温度为 $2 0 ^ { \circ } \mathrm { C } \pm 3 ^ { \circ } \mathrm { C }$ 、相对湿度为 $( 5 0 \pm 1 0 )$ %的条件下养护;

完全干燥后 连同玻璃板完全浸没在水中 水的温度保持在 $2 0 ^ { \circ } \mathrm { C } \pm 3 ^ { \circ } \mathrm { C }$ ;

d) 浸水时间为1 h,观察膜是否溶解。

### 6.6 成膜耐热性养生剂成膜耐热性的试验方法按如下规定进行

将养生剂按试验规定的用量涂于玻璃板上 涂覆面积不小于 $1 5 0 \ \mathrm { m m } \times 1 5 0 \ \mathrm { m m }$ ;

b) 放在温度为 $2 0 ^ { \circ } \mathrm { C } \pm 3 ^ { \circ } \mathrm { C }$ 、相对湿度为 $( 5 0 \pm 1 0 )$ %的条件下养护4 h;

c) 待完全干燥后,置于 $6 5 \mathrm { ~ } ^ { \circ } \mathrm { C } \pm 2 \mathrm { ~ } ^ { \circ } \mathrm { C }$ 的烘箱内,恒温10 min 后,观察是否出现熔化、变色现象。

### 6.7 密封性养生剂密封性的试验方法按如下规定进行:

将养生剂按试验规定用量涂于玻璃板上 涂覆面积不小 $\mathbb { F } 1 5 0 \mathrm { ~ m m } \times 1 5 0 \mathrm { ~ m m } ;$

b) 放在温度为 $2 0 ^ { \circ } \mathrm { C } \pm 3 ^ { \circ } \mathrm { C }$ 、相对湿度为 $( 5 0 \pm 1 0 )$ % 的条件下养护 4 h;

c) 待完全干燥后,目测其成膜是否连续,是否有透孔。

a) 制作 $1 5 0 ~ \mathrm { m m } \times 1 5 0 ~ \mathrm { m m } \times 1 5 0 ~ \mathrm { m m }$ 的混凝土标准试件 试验所用原材料及配合比满足 JGJ 55 的要求 用水量以混凝土坍落度控制在 $4 0 \ \mathrm { m m } \pm 1 0 \ \mathrm { m m }$ 为准;

b) 当混凝土标准试件表面不见浮水 且达初凝后 将 $1 8 0 ~ \mathrm { m m } \times 1 8 0 ~ \mathrm { m m }$ 的养生膜浸泡在蒸馏水中使其吸水饱和 然后平整覆盖在试件表面上 养生膜同标准试件上表面边缘用透明胶带密封好;

### 6.16 单位面积吸蒸馏水量单位面积吸蒸馏水量应按如下规定进行:

$$
g = \left(w _ {1} - w _ {0}\right) / 1. 0\tag{…… (1}

## 有效保水率试验方法

### A.1 仪器设备

试验用仪器要求如下:

———60 L 混凝土标准单卧轴式强制搅拌机。

———混凝土标准振动台。

———塑料试模: $1 5 0 ~ \mathrm { m m } \times 1 5 0 ~ \mathrm { m m } \times 1 5 0 ~ \mathrm { m m } $ 。

———环境箱(室):

a) 控制环境温度: $3 5 ^ { \circ } \mathrm { C } \pm 2 ^ { \circ } \mathrm { C }$ ;

b) 相对湿度: $( 4 0 \pm 5 )$ % ;

c) 风速: $\mathrm { . 0 . 5 ~ m / s } \pm 0 . 2 ~ \mathrm { m / s } _ { \mathrm { c } }$

———电子天平:称量 20 kg,感量 0. 1 g。

### A.2 原材料及配合比

试验所用的水泥、砂、石、水等原材料及配合比应按照6.1 的要求进行。

### A.3 试验步骤

#### A.3.1 基准混凝土的制备

A.3.1.1 试件制备的环境条件如下

a) 温度: $: 2 0 ^ { \circ } \mathrm { C } \pm 5 ^ { \circ } \mathrm { C }$

b) 相对湿度: $( 5 0 \pm 1 0 ) \%$ 。

A. 3. 1. 2 试验步骤如下:

a) 采用60 L 单卧轴式强制搅拌机,成型混凝土的全部材料一次性投入搅拌机,用水量应使混凝土拌和物坍落度达到 $4 0 \ \mathrm { m m } \pm 1 0 \ \mathrm { m m }$ ,拌和量不少于 20 L,不大于 45 L;

b) 搅拌 3 min,出料后人工翻拌 2 次～3 次;

c) 按 GB/T 50080 的规定测定混凝土坍落度,应控制在 $4 0 \ \mathrm { m m } \pm 1 0 \ \mathrm { m m }$ 的范围内。

#### A.3.2 试件的制作

A.3.2.1 试模 使用塑料试模 成型前将试模底部的气孔用胶带密封好 不宜在模子内抹过多的脱模剂或油 特别是顶部边缘要密封的地方

A.3.2.2 试件成型:按 GB/T 50081 进行,顶面须用抹刀抹平,并沿试模内壁插入数次,缺料处用砂浆找平,使顶面均匀密实,没有空隙和裂缝。 成型后清理干净模子外缘,水平放置。

A.3.2.3 试件数量:基准试件每组四个;喷涂养生剂或覆盖养生膜试件每组四个。

#### A.3.3 试件表面的制备与边缘密封

A.3.3.1表面制备：待试件表面水消失后用于净毛刷轻刷试件表面釉层 应以刷不出表面水或用手指轻擦过表面无水迹为适宜的表面条件

A.3.3.2 基准试件组试件表面条件达到要求后,立即称量基准试件质量 $m _ { 1 }$ ,精确到 0.1 g,放入环境

箱中,记下入箱时间。

A.3.3.3 喷涂养生剂试件的表面条件达到要求后,在试模和试件边缘间,剔出一深 3 mm、宽不大于3 mm 的 V 形槽,用密封胶或蜡等密封材料填充,封边后立即对试件称重,质量为 $M _ { 1 }$ ,精确到 0. 1 g。

A.3.3.4 覆盖养生膜材的试件表面条件达到要求后,立即称取试件质量 $M _ { 4 }$ ,精确到0.1 g,然后覆盖养生膜 用塑料胶带封边 放入环境箱中 记下入箱时间

#### A.3.4 养生剂的喷涂

A.3.4.1 根据生产厂家推荐用量,计算养生剂的喷涂量 $M _ { \mathrm { c } }$ ,如无特别要求,以 $0 . 2 ~ \mathrm { k g } / \mathrm { m } ^ { 2 }$ 的用量为准。试件喷涂面积以试件净尺寸计算。

A.3.4.2 按规定用量,在试件顶部均匀的喷涂养生剂,不得有漏喷、漏涂或明显不均匀的情况存在,每个试件一次完成。

A.3.4.3 通过比较喷涂前后试件质量 确定养生剂喷涂量是否达到要求 达到要求后 立即称量喷涂养生剂试件质量 $M _ { 2 }$ .精确到0.1 ${ \bf g } _ { \circ }$ 整个喷涂时间不得超过 如果最终的养生剂用量与计算用量相差超过10%,试件无效。

#### A.3.5 试件的养护

A. 3. 5. 1 环境箱温度: $3 5 ^ { \circ } \mathrm { C } \pm 2 ^ { \circ } \mathrm { C }$ ;相对湿度: $( 4 0 \pm 5 )$ % ;风速: $\mathrm { : 0 . 5 ~ m / s } \pm 0 . 2 ~ \mathrm { m / s } .$ 。

A.3.5.2 立即将喷涂过养生剂或覆盖养生膜材的试件放入环境箱内 并分别记录喷涂养生剂的试件或覆盖养生膜材的试件和基准试件放入养护箱时间

A.3.5.3 基准试件和喷涂养生剂试件或覆盖养生膜材的试件应等间距均匀地摆放在环境箱内后 取出称其质量 称得基准试件试验最终质量 $\left( m _ { 2 } \right)$ 喷涂养生剂试件最终质量 $\left( M _ { 3 } \right)$ 覆盖养生膜材的试件除去覆盖膜材后的最终质量 $( M _ { 5 } )$ ,称量精确到0.1 g。

#### B.3.1 按 GB/T 50081 规定的方法分别成型抗压试件和弯拉强度试件。

#### B.3.2 待试件表面水消失后,用干净毛刷轻刷表面釉层,应以刷不出表面水或用手指轻擦过表面无水迹为适宜的表面条件。

#### B.3.3 养生剂的喷涂 试件表面条件达到要求后 在试模和试件边缘间 剔出一个深 宽不大于3 mm 的 V 形槽,用密封胶和蜡密封材料填充、封边;并根据生产厂家推荐的用量喷涂,如无特别要求,以 $0.2 ~ \mathrm { k g } / \mathrm { m } ^ { 2 }$ 的用量为准 试件喷涂面积以试件净尺寸计算 不得有漏喷或不均匀的现象 每个试件一次完成。

#### B.3.4 养生膜的铺覆:试件表面条件达到要求后,铺覆养生膜材,用塑料胶带封边(带模)。

#### B.3.5 试件的养护:将喷涂养生剂(带模)或覆盖养生膜的试件(带模)置于室内养护,养护室温度为20°C ± 5°C ,相对湿度为 (50 ± 10)%。

#### B.3.6 基准试件的养护 按照 GB/T 50081 的规定进行 标准养护室温度为20°C ± 2°C相对湿度大于 95% 。

#### B.3.7 基准试件和喷涂养生剂或覆盖养生膜材的试件养护至要求龄期 分别测定抗压强度或弯拉强度 计算混凝土抗压强度比或弯拉强度比

### B.4 结果计算

#### B.4.1 抗压强度比以喷涂养生剂混凝土与基准混凝土同龄期抗压强度之比表示,按公式(B.1)计算:

$$
R _ {\mathrm{s}} = \frac {S ^ {\prime}}{S} \times 100 \%\tag{B.1}
$$

式中:

$R _ { \mathrm { s } }$ ———抗压强度比;

<!-- 第 12 页 -->

$S$ ———基准混凝土的抗压强度,单位为兆帕(MPa);

$S ^ { \prime }$ ———涂养生剂或覆盖养生膜混凝土的抗压强度,单位为兆帕(MPa)；

#### B.4.2 抗压强度按 GB/T 50081 进行试验及计算。 抗压强度比以每组涂养护剂或覆盖养生膜试件与基准同龄期试件抗压强度的代表值之比表示,计算结果精确至1%。

#### B.4.3 弯拉强度比以涂养生剂混凝土与基准混凝土同龄期弯拉强度之比表示,按公式(B.2)计算:

$$
R _ {\mathrm{f}} = \frac {f ^ {\prime}}{f} \times 100 \%\tag{B.2}
$$

式中:

$R _ { \mathrm { f } }$ ———弯拉强度比;

$f$ ———基准混凝土的弯拉强度,单位为兆帕(MPa);

$f ^ { \prime }$ ———涂养生剂或覆盖养生膜混凝土的弯拉强度 单位为兆帕 $\mathrm { ( M P a ) }$ ；

#### B.4.4 弯拉强度按 进行试验及计算 弯拉强度比以每组涂养护剂或覆盖养生膜试件与基准同龄期试件弯拉强度的代表值之比表示,计算结果精确至1%。

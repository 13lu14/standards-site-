 引 言

公路机电设施在提高公路运营管理效率、保障交通运输安全等方面发挥了重要的作用,在公路行业获得了广泛的应用 公路机电设施主要用电设备能效等级及评定方法 系列标准根据不同公路机电设施产品功能要求 性能指标和能耗特点等的不同将标准分为五个部分

第 部分 车道控制标志 明确了 车道控制标志产品的能效评定方法和能效等级划分。

———第2 部分:公路隧道通风机。 明确了公路隧道通风机产品的能效评定方法和能效等级划分。

———第3 部分:公路隧道照明系统。 明确了公路隧道照明系统的能效评定方法和能效等级划分。

第 部分 公路 可变信息标志 明确了公路 可变信息标志产品的能效评定方法和能效等级划分。

第 部分 公路 照明灯具 明确了公路 照明灯具产品的能效评定方法和能效等级划分。

LED 车道控制标志作为文件第1 部分,能效评定方法以 JT/T 597《LED 车道控制标志》的规定为基础,能效等级的指标综合考虑了国内生产企业的整体水平,标准内容力求满足适用性、先进性、可操作性的编制原则。

## 6 评定方法

### 6.1 试验条件

6.1.1 环境温度：$15\ ^{\circ}\mathrm{C} \sim 35\ ^{\circ}\mathrm{C}$。

7. 1. 2 相对湿度:35% \~ 75% 。

6.1.3 大气压力：$85\ \mathrm{kPa} \sim 106\ \mathrm{kPa}$。

6.1.4 环境照度:LED 车道控制标志测试面表面照度小于500 lx。

### 6. 2 试验仪器

#### 6. 2. 1 亮度计

亮度计的计量性能应符合 JJG 211—2005 规定的一级要求,测量范围不小于 $\left( 0 \sim 2 0 ~ 0 0 0 \right) ~ \mathrm { c d / m } ^ { 2 }$ 。

#### 6.2.2 功率测量仪表

功率测量仪表的准确度等级应符合JJG 124—2005 规定的0.5级要求，测量范围不小于 $(0 \sim 100)\ \mathrm{W}$。

### 6.3 检测样本数量

车道控制标志进行能效评定测试时 送样检测的样品数量应不少于 台完整的 车道控制标志产品;抽样检测的样品数量宜不少于抽样批次 LED 车道控制标志总数量的3%,且不少于3 台完整的产品。

### 6.4 试验方法

接通电源 点亮 车道控制标志 调节 车道控制标志的发光亮度 使其笔画平均亮度分别达到不小于 $4 \ 0 0 0 \ \mathrm { c d } / \mathrm { m } ^ { 2 }$ (红色)和 $5 ~ 0 0 0 ~ \mathrm { c d } / \mathrm { m } ^ { 2 }$ (绿色)的水平,测试功率和功率因数的测试步骤如下:

a) 接通电源,点亮 LED 车道控制标志,使其只显示红色叉号;

亮度计视场角选择 沿 车道控制标志像素法向方向 在不同位置均匀选择不少于五个测试点 分别测试其亮度值 $\left( L _ { i } \right) \left( i = 1 , 2 , 3 , \cdots , n \right)$ ;

c) 按照式(1)计算亮度的平均值 $L { \mathrm { : } }$ ;

$$
L = \frac {\sum_ {i = 1} ^ {n} L _ {i}}{n}\tag{……(1}
$$

式中:

$L$ 车道控制标志笔画亮度平均值 单位为坎德拉每平方米 $( \mathrm { { c d } } / \mathrm { { m } } ^ { 2 } )$ ;

$L _ { i }$ 车道控制标志测试点的亮度值 单位为坎德拉每平方米 $( \mathrm { { c d } } / \mathrm { { m } } ^ { 2 } )$ ;

$n$ ———测试点数量。

<!-- 第 2 页 -->

d) 如果 L 小于 $4000\ \mathrm{cd/m^2}$，调节LED 车道控制标志的发光亮度，重复b)、c)步骤，直到L 不小于 $4000\ \mathrm{cd/m^2}$，采用功率测量仪表测试此时的 LED 车道控制标志的功率 $W_{\text{红}}$ 和功率因数并记录；

e) 关闭红色叉号,调节 LED 车道控制标志,使其只显示绿色箭头;

f) LED 车道控制标志绿色箭头的笔画平均亮度测试重复 b)、c)步骤;

g) 如果L 小于 $5000\ \mathrm{cd/m^2}$，调节LED 车道控制标志的发光亮度，重复b)、c)步骤，直到L 不小于 $5000\ \mathrm{cd/m^2}$，采用功率测量仪表测试此时的 LED 车道控制标志的功率 $W_{\text{绿}}$ 和功率因数并记录。

### 6.5 能效计算

按照式(2)计算 LED 车道控制标志的能效(η)。

$$
\eta = \frac {W _ {\text {红}} + W _ {\text {绿}}}{2}\tag{……(2}
$$

式中:

η ———LED 车道控制标志能效,单位为瓦特(W);

$W红$ ———LED 车道控制标志显示红色叉号工况下的功率值,单位为瓦特(W);

$W绿$ ———LED 车道控制标志显示绿色箭头工况下的功率值,单位为瓦特(W)。

### 6. 6 能效等级评定

将计算的 车道控制标志能效与表 中的数据进行比较 确定所测试的 车道控制标志能效等级。

 基桩高应变仪检定规程

## 1 范围

本规程适用于基桩高应变仪的首次检定、后续检定和使用中检查。

## 2 概述

基桩高应变仪主要用于检测单桩轴向抗压承载力和桩身完整性 基桩高应变仪由加速度传感器 应变传感器 适配器 配套电缆及主机等组成 结构示意图见图 基桩高应变仪工作原理是在桩顶施加高能量冲击荷载 传感器采集信号 自动绘制出速度曲线和力曲线，运用波动理论反演来推算被检桩的完整性、轴向抗压极限承载力。

![](images/JJG%EF%BC%88%E4%BA%A4%E9%80%9A%EF%BC%89144%E2%80%942020%20%E5%9F%BA%E6%A1%A9%E9%AB%98%E5%BA%94%E5%8F%98%E4%BB%AA.assets/7c6c2ef653cc092fcf86e5c6584f437341db6bccb1940d4fb43d4c82c3864f02.jpg)

说明：

1———加速度传感器； 2———应变传感器； 3———适配器；4———配套电缆； 5———主机

## 4 通用技术要求

## 4.1 外观

#### 4.1.1 基桩高应变仪产品表面的涂镀层应牢固、均匀，不应有影响正常工作的脱落、起泡、锈蚀、磨损等缺陷。

#### 4.1.2 基桩高应变仪的零部件应紧固无松动 键盘 开关 按钮和其他控制部件的控制应灵活可靠。

#### 5.3.3 加速度幅值线性度加速度幅值线性度检定步骤如下：

a） 使基桩高应变仪加速度传感器与标准冲击加速度传感器以背靠背的方式刚性连接于标准冲击台落锤上；

b） 连接标准冲击加速度套组与动态信号分析仪，设置基桩高应变仪加速度传感器灵敏度为出厂值；

c） 根据基桩高应变仪加速度传感器的测量范围，均匀选取不少于7 个检定点（应包含最小和最大幅值 一般情况下选取最小幅值为 $5 0 0 \mathrm { m } / \mathrm { s } ^ { 2 }$ 最大幅值为 $1 0 0 0 0 \mathrm { m } / \mathrm { s } ^ { 2 } )$ 将落锤从低到高依次提升至各检定点对应的高度并迅速释放 使其自由降落并与砧头碰撞后产生冲击信号，读取每个检定点的基桩高应变仪输出电压幅值$( S _ { i } )$ 和动态信号分析仪采集的加速度幅值 $\left( \boldsymbol { a } _ { i } \right)$

d） 用最小二乘法线性拟合，获得截距 $( S _ { 0 } )$ 和斜率（K），按式（1）计算基桩高应变仪输出电压幅值的拟合值：

$$
\widetilde {S} _ {i} = S _ {0} + K a _ {i}\tag{1}
$$

式中： $\widetilde { S } _ { i }$ ———基桩高应变仪输出电压幅值的拟合值（mV）；

$S _ { 0 }$ ———截距（mV）；

K 斜率 即被检基桩高应变仪加速度传感器灵敏度 $\left[ \mathrm { m } \mathrm { V } / ( \mathrm { m } / \mathrm { s } ^ { 2 } ) \right]$ 。

<!-- 第 3 页 -->

按式 计算幅值线性度 $\gamma$ 取 $\gamma$ 中的绝对值最大值作为加速度幅值线性度检 $\gamma _ { i }$ $\gamma _ { i }$ 定结果；

$$
\gamma_ {i} = \frac {S _ {i} - \widetilde {S} _ {i}}{S _ {i \mathrm{M}}} \times 100 \%\tag{2}
$$

式中： $S _ { i \mathrm { M } }$ ——— ${S } _ { i }$ 中最大值（mV）；

#### 5.3.4 加速度频率响应误差加速度频率响应误差检定步骤如下

a） 将基桩高应变仪加速度传感器与标准振动加速度传感器以背靠背的方式安装于标准振动台中央位置，连接动态信号分析仪与标准振动加速度套组；

b） 设置标准振动台的参数，推荐参考频率点为160Hz，标准振动幅值为 $1 0 0 \mathrm { m } / \mathrm { s } ^ { 2 }$ ；

c） 在全频段内选择不少于 7 个频率点，推荐频率为 10Hz、20Hz、40Hz、80Hz、160Hz、320Hz、650Hz、1 250Hz、2 000Hz，在标准振动台幅值不变的条件下，逐个改变频率点，在基桩高应变仪上测出每一频率点的幅值，以参考频率点的振动幅值作为参考值 $\left( \boldsymbol { x } _ { 0 } \right)$ 按式 计算每个频率点的幅值相对误差 $\delta _ { i }$ 取 $\delta _ { i }$ 中的绝对值最大值作为加速度频率响应误差检定结果

$$
\delta_ {i} = \frac {x _ {i} - x _ {0}}{x _ {0}} \times 100 \%\tag{3}
$$

式中： ${ \bf} \delta _ { i }$ ———第 i 个频率点的幅值相对误差；

$x _ { i }$ ———基桩高应变仪每个频率点测得的幅值（mV）；

#### 5.3.5 应变幅值线性度应变幅值线性度检定方法如下：

a） 固定应变传感器于标准应变发生装置上，连接应变传感器与基桩高应变仪主机，用位移测量仪表测量初始标距

b） 在传感器满量程范围内均匀地划分10 级位移增量，读取基桩高应变仪的应变初始值作为零点输出；

c） 由低到高逐级调整标准应变发生装置的位移，达到每级位移增量值并稳定后，记录基桩高应变仪应变数据采集器的输出电压和位移测量仪表数值

d） 用最小二乘法线性拟合，获得应变传感器的系统灵敏度（Z）；

注：以基桩高应变仪应变数据采集器输出的电压值作为X 位移测量仪表读数除以应变传感器初始标距得到的应变值作为 $Y _ { \circ }$

e） 按式（4）计算应变幅值线性度 $\eta$ ：

$$
\eta = \frac {\Delta Y _ {\max}}{Y} \times 100 \%\tag{4}
$$

式中： $\Delta Y _ { \mathrm { { m a x } } }$ ———实测曲线与拟合直线间的最大偏差（mV）；

$Y$———基桩高应变仪应变数据采集器的满量程输出（mV）；

#### 5.3.6 应变重复性按

#### 5.3.5 中 a） ～d）步骤并反复进行5 次测量，选取各级位移增量对应的测试点，按4式（5）计算应变重复性 $\xi _ { \mathrm { R } }$ ，取 $\xi _ { \mathrm { R } }$ 中最大值作为应变重复性检定结果。

<!-- 第 4 页 -->

$$
\xi_ {\mathrm{R}} = \frac {S _ {\mathrm{Zn}}}{\overline{Z} _ {\mathrm{n}}} \times 100 \%\tag{5}
$$

式中： $S _ { \mathrm { z n } }$ ———5 次测量应变传感器灵敏度的标准偏差 $\left( { \mu } \varepsilon / \mathrm { m V } \right)$ ；

$\overline { { Z } } _ { \mathrm { n } }$ ———5 次测量应变传感器灵敏度的平均值 $\left( { \mu } \varepsilon / \mathrm { m V } \right)$ ；

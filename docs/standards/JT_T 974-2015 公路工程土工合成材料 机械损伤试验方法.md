 公路工程土工合成材料 机械损伤试验方法

## 1 范围

本标准规定了土工合成材料机械损伤的试验方法，包括试验环境条件、试验设备与材料、试样制备、试验步骤、测试评价和试验报告。

本标准适用于公路工程土工合成材料土工格栅的机械损伤试验，其他土工合成材料参考使用。

下列术语和定义适用于本文件。

## 4 试验环境条件

试验温度宜在 $1 0 ^ { \circ } \mathrm { C } \sim 4 0 ^ { \circ } \mathrm { C }$ ，且不能在雨雪天气下进行。

## 5 试验设备与填料

### 5.1 压实机械
应选择实际工程拟使用的压实机械。若未指定,则根据 5.3 选定的典型填料,依据 JTG F10 确定典型压实机械。

### 5.2 其他仪器设备和工具
其他仪器设备和工具如下：

<!-- 第 1 页 -->

a) 摊铺填料的机械和工具：装载机、推土机、平地机、铁锹；

b) 钢板尺：最小刻度 1mm，量程 500mm；

c) 拉力试验仪器：符合 JTG E50 中 T 1121 要求的拉力测试仪器；

d) 颗粒筛分测试仪器：符合 JTG E40 中 T 0115 要求的测填料颗粒级配的仪器；

e) 压实度测试仪器：符合 JTG E60 中 T 0921、T 0923 要求的测压实度的仪器；

f) 裁剪工具：用于裁切土工合成材料试样的剪刀、割刀、锯等。

### 5.3 填料
应选用与工程相同的填料。当工程未指定时,应依据 JTG C20 选用典型的填料：

——碎石：粒径大于20mm 的颗粒质量超过总质量的50%，且最大粒径不超过200mm；

——角砾：粒径大于2.0mm 的颗粒质量超过总质量的50%，且最大粒径不超过20mm；

——粗砂：粒径大于0.5mm 的颗粒质量超过总质量的50%，且最大粒径不超过2mm。

填料级配依据 JTG E40 中 T 0115 筛分法确定，并做出颗粒级配曲线。

## 6 试样制备

### 6.1 确保每种施工方法下都有用于评估的样品。 所取样品应为全幅宽，长度不小于1m，且至少包含两个完整的结构单元。

### 6.2 对试验样品做好标识，以便在试验过程中能够正确辨识。

### 6.3 从试验样品的同卷产品中，裁剪出对比样，用于拉力测试，可与试验样品的拉伸强度做对比。

### 6.4 取样时，应避免造成样品损伤。

### 6.5 试样的所有信息资料，如生产时间、生产厂家、规格型号、纵向横向和卷号等都应记录齐全并标识清楚。

## 7 试验步骤

### 7.1 制备土基用压实机械将松铺厚度为300mm 的典型填料压实为压实度不小于90%的土基。 压实后每平方米的平整度为 填料的压实厚度可用钢板尺测量 压实度的测试依据为

### 7.2 铺设试样在土基上平整铺设试样，对其不能施加预张力，试样的铺设方向与压实方向垂直。

### 7.3 铺设填料试样上下方的填料应相同 卸料时 机具不得在未覆盖填料的试样上行驶 不得扰动下层的试样避免对试样造成损伤 可用机械和人工摊铺 并做好记录 松铺厚度根据选择的压实机械及压实度试验确定。

### 7.4 压实

#### 7.4.1 将填料压实，每层填料压实厚度应为300mm。 根据JTG F10 的要求，填料压实度应不小于94%。

#### 7.4.2 每种填料采用三种压实方式

a) 标准压实：将填料压实到7.4.1 中要求的厚度及压实度；

b) 过量压实：用两倍 a)的碾压遍数碾压上述的填料到指定的厚度；

<!-- 第 2 页 -->

c) 双层压实：依照 a)的碾压遍数碾压第一层填料到指定的厚度，再摊铺第二层填料，并用 a)的碾压遍数碾压到指定的厚度。

注：在试验前应先进行压实试验，依次确定在三种不同压实要求下，压实到指定厚度时的松铺厚度及碾压遍数。

#### 7.4.3 压实机械运行的方向应与工程指定的一致 若采用典型填料 则运行方向应垂直于铺设的土工合成材料的主强度方向。

#### 7.4.4 压实后每平方米的平整度为 $- 2 0 \mathrm { m m } \sim \mathrm { ~ } + 2 0 \mathrm { m m }$ 。

### 7.5 试样取出

#### 7.5.1 应在压实完成48h 内取出试样。

#### 7.5.2 取出时应防止对试样造成二次损伤，且记录取样的方法。

#### 7.5.3 由于取出对试样造成的损伤，需进行位置标记，避免该位置用于评价。

#### 7.5.4 保存好取出的试样，避免受到额外的损伤。

## 8 测试评价

### 8.1 外观评估对每个试样的机械损伤情况进行外观评估并记录，外观损伤分为四个类型：

a) 轻微磨损：在土工合成材料表面上的轻微刮擦或磨损；

b) 挫伤：土工合成材料表面严重磨损、挫伤，但无光线透过，或者涂层剥落；

c) 裂缝：局部开裂形成许多小裂缝，光能通过；

d) 切断：发生剪断破坏或出现孔洞。

### 8.2 拉力测试

#### 8.2.1 依据 ISO 10319 或 JTG E50 测试对比样及机械损伤样的拉伸强度(如测试结果不一样，以 ISO10319 为仲裁)。

#### 8.2.2 将每种机械损伤样的拉伸强度与对比样进行比较

#### 8.2.3 强度保持率 按式 计算强度保持率

$$
R _ {\mathrm{T}} = \frac {T _ {1}}{T _ {0}} \times 100 \%\tag{1}
$$

式中： $R _ { \mathrm { T } }$ ———强度保持率；

$T_1$ ———机械损伤样的拉伸强度，单位为千牛每米 $\left( \mathrm { k N } / \mathrm { m } \right)$ ；

$T _ { 0 }$ 对比样拉伸强度 单位为千牛每米 $\left( \mathrm { k N } / \mathrm { m } \right)$ ；

在同一填料、不同压实方式下，若同种产品的强度保持率不同，则取最小值。

#### 8.2.4 机械损伤折减系数：按式(2)计算机械损伤折减系数，其与强度保持率为倒数关系。

$$
F _ {\mathrm{id}} = \frac {T _ {0}}{T _ {1}}\tag{2}
$$

式中： $F _ { \mathrm { i d } }$ ———机械损伤折减系数；

$T _ { 1 }$ ———机械损伤样的拉伸强度 单位为千牛每米 $\left( \mathrm { k N } / \mathrm { m } \right)$ ；

$T _ { 0 }$ ———对比样拉伸强度 单位为千牛每米 $\left( \mathrm { k N } / \mathrm { m } \right)$ ；

在同一填料 不同压实方式下 若同种产品的折减系数不同 则取最大值

## 9 试验报告

报告要包含以下信息：

<!-- 第 3 页 -->

a) 机械设备、工具的类型及型号，试验步骤，测试设备型号，测试方法；

b) 填料类型，填料的颗粒级配曲线、最大粒径，松铺厚度、碾压遍数、碾压速度、压实度、压实厚度；

c) 土工合成材料试样信息，如生产厂家、规格型号、卷号、材料级别类型等；

d) 试验布局图；

e) 机械损伤的典型照片及外观评价记录；

f) 损伤样及对比样的拉力试验测试的结果；

g) 损伤样的强度保持率、机械损伤折减系数等。

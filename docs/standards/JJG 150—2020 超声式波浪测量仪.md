 超声式波浪测量仪检定规程

## 1 范围

本规程适用于超声式波浪测量仪的首次检定、后续检定和使用中检查。

## 2 概述

超声式波浪测量仪（以下简称“测波仪”）是一种适用于港口码头及沿海台站测量波浪时空分布特性的仪器。

测波仪主要由声学换能器、水下支架、通信电缆、发射单元和控制处理单元（包括控制计算机和处理软件）等部分组成。

测波仪的工作原理是将不同夹角的超声波束从水底向水面发射，根据回声测距原理测量波高及波周期，依据声学多普勒频移原理测量波向。 测波仪工作原理图见图1。

## 4 通用技术要求

## 4.1 外观测波仪表面涂覆层应均匀、牢固，换能器表面不应有脱落、划伤、锈迹、水中生物附着等。

## 4.2 铭牌测波仪应有清晰的铭牌，标有产品名称、型号、生产厂家、仪器编号及出厂日期等。

## 5 计量器具控制

## 5.1 检定条件
#### 5.1.1 检定环境条件环境条件要求如下：

a） 温度： $2 0 ^ { \circ } \mathrm { C } \pm 1 5 ^ { \circ } \mathrm { C }$

b） 相对湿度：应不大于90％。

#### 5.1.2 检定设施及设备检定设施及设备要求如下：

a） 水槽：长度应不小于50m，宽度应不小于1.5m，深度应不小于1.5m，水体中含有悬沙或藻类等散射物质。

b） 激光测距仪：测量范围0 ～100m，准确度等级2 级。

c） 计时器：测量范围 $0 \sim 1 \times 1 0 ^ { 6 } \mathrm { s }$ ，最大允许误差 $\pm 0 . 0 0 1 \mathrm { s } .$ 。

d） 角度转盘：与测波仪安装支架同轴，测量范围 $0 ^ { \circ } \sim 3 6 0 ^ { \circ }$ ，最大允许误差 $\pm 0 . 1 ^ { \circ } $ 。

e） 试验车，要求如下：

1） 运动模式可设置为波浪运动模式和直线运动模式；

2） 波浪运动模式下，可设置模拟波高和模拟波周期，模拟波高最大允许误差 $\pm 0 . 0 1 \mathrm { m }$ ，模拟波周期最大允许误差 $\pm 0 . 0 5 \mathrm { s }$ ；

3） 直线运动模式下，可设置车速，车速最大允许误差 $\pm 0 . 0 5 \mathrm { m / s }$ 。

#### 5.3.3 示值误差
5.3.3.1 波高示值误差检定步骤如下：a） 安装测波仪在试验车的安装支架上，使测波仪声学换能器发射的波束声轴线与水槽长边平行，垂直于水槽短边反射壁。

b） 降低安装支架至水面以下，调节测波仪至1／2 水深处并启动测波仪，检定示意图见图 2。

2———测波仪； 5———波束。

3———短边反射壁；

图2 测波仪波高检定示意图

c） 设置试验车运动模式为波浪运动模式，设定模拟波高为 0. 3m，模拟波周期为30.0s，按式（1）计算测波仪声学换能器距水槽短边反射壁的距离。

$$
L = \frac {H _ {\mathrm{B}}}{2} + 1\tag{1}
$$

式中：$L$———声学换能器距水槽短边反射壁的距离（m）；

$H _ { \mathrm { B } }$ ———标准波高值（试验车设置的模拟波高）（m）；

d） 移动试验车至 L 位置处，启动试验车开始往复运动，稳定运行1min 后，在测波仪上连续读取并记录10 个波高示值，按式（2）计算波高示值误差。

$$
\Delta H = \overline {{H}} _ {\mathrm{s}} - H _ {\mathrm{B}}\tag{2}
$$

式中： $\Delta H$ ———测波仪波高示值误差（m）；

$\overline{H} _ { \mathrm { s } }$ ———测波仪波高算术平均值（m）；

e） 依次设定试验车的模拟波高为 5. 0m、10. 0m、15. 0m、20. 0m、25. 0m，按 5. 3. 3. 1c） ～d）步骤完成波高检定试验，取各检定点波高示值误差的绝对值最大值作为波高示值误差的检定结果。
<!-- 第 3 页 -->

5.3.3.2 波周期示值误差检定步骤如下：a） 按 5. 3. 3. 1a） ～ b）的步骤安装测波仪。

b） 设置试验车为波浪运动模式，设定模拟波高为5.0m，模拟波周期为 $5 . 0 \mathrm { s }$ ；

c） 启动试验车开始往复运动，稳定运行1min 后，在测波仪上连续读取并记录10 个波周期示值，按式（3）计算波周期示值误差。

$$
\Delta T = \overline {{T}} _ {\mathrm{s}} - T _ {\mathrm{B}}\tag{3}
$$

式中： $\Delta T $ ———测波仪波周期示值误差（s）；

$\overline{T} _ { \mathrm { { s } } }$ —测波仪波周期算术平均值（s）；s

$T _ { \mathrm { { B } } }$ ———标准波周期值（试验车设置的模拟波周期）（s）；

d） 依次设定试验车的模拟波周期为 10. 0s、15. 0s、20. 0s、25. 0s、30. 0s，按 5. 3. 3. 2b） ～步骤完成波周期检定试验 取各波周期示值误差的绝对值最大值作为波周期示值误差的检定结果。

5.3.3.3 波向示值误差检定步骤如下：a） 将测波仪安装在试验车的安装支架上，使测波仪声学换能器发射的波束声轴线垂直于水槽底面，测波仪方向指示标记与安装支架上角度转盘零刻线重合。

b） 降低安装支架至水面以下，转动角度转盘，使测波仪方向指示标记与水槽长边平行，指向试验车前进方向，测波仪波向检定示意图见图 $3 ,$ ；

启动试验车沿水槽直线运动 待试验车进入匀速运动状态 在测波仪上连续读取并记录 个波向示值 按式 计算波向示值误差

e） 转动角度转盘，使角度依次为 $4 5 ^ { \circ } \ : , 9 0 ^ { \circ } \ : , 1 3 5 ^ { \circ } \ : , 1 8 0 ^ { \circ } \ : , 2 2 5 ^ { \circ } \ : , 2 7 0 ^ { \circ } \ : , 3 1 5 ^ { \circ } \ : , 3 6 0 ^ { \circ }$ ，按5.3.3.3b） ～ d）步骤完成波向检定试验，取各波向示值误差的绝对值最大值作为波向示值误差的检定结果；

#### 5.3.4 重复性波高、波周期和波向重复性检定步骤如下：

a） 将试验车参数设置为波高 8. 0m、波周期 16s，按 5. 3. 3. 1 和 5. 3. 3. 2 的方法重复测量10 次，按式（5）计算波高重复性，按式（6）计算波周期重复性。

$$
s _ {\delta} = \sqrt {\frac {\sum (h _ {i} - \bar {h}) ^ {2}}{n - 1}}\tag{5}
$$

式中： $: s _ { \delta }$ ———波高重复性（m）；

$h _ { i }$ ———测波仪第 i 次测量的波高示值（m）；

$\bar { h }$ ———测波仪 10 次波高测量的算术平均值（m）；

$n$———测量次数；

$$
s _ {\sigma} = \sqrt {\frac {\sum (t _ {i} - \bar {t}) ^ {2}}{n - 1}}\tag{6}
$$

式中 $: s _ { \sigma }$ ———波周期重复性（s）；

$t _ { i }$ ———测波仪第 i 次测量的波周期示值（s）；

$\overline{t}$———测波仪10 次波周期测量的算术平均值（s）；

b） 选择 $4 5 ^ { \circ }$ 波向值，按 5. 3. 3. 3 的方法重复测量 10 次，按式（7）计算波向重复性；

$$
s _ {\lambda} = \sqrt {\frac {\sum (d _ {i} - \overline {{d}}) ^ {2}}{n - 1}}\tag{7}
$$

式中 $: s _ { \lambda }$ ———波向重复性（°）；

$d _ { i }$ ———测波仪第 i 次测量的波向示值（°）；

$\bar{d}$ ———测波仪10 次波向测量的算术平均值（°）；

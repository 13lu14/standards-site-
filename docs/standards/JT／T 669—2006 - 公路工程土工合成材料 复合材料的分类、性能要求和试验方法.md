# 公路工程土工合成材料 复合材料的分类、性能要求和试验方法

## 1 范围

本标准规定了复合材料的术语和定义、分类、性能要求和试验方法。

本标准适用于公路路基等工程用的复合材料。水运、铁路、水利、建筑、环保和农业等领域工程用复合材料可参照执行。

## 3 术语和定义

下列术语和定义适用于本标准。

复合材料 composite materials

按工程应用的功能要求,有选择地将多种不同类型的土工合成材料产品复合成为一体的复合型制品。

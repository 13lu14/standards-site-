用于公路工程隧道混凝土结构表面，能形成耐火隔热保护层的涂料。

## 4 产品分类和标记

## 4． 1 产品分类

隧道防火涂料按材料耐火极限分类为

a） Ⅰ型：按 GA／ T 714 规定的 RABT 升温曲线测试，满足耐火极限不低于 2． 00h 的要求；

b） Ⅱ型：按 GA／T 714 规定的 RABT 升温曲线测试，满足耐火极限不低于1．50h 的要求；

c） Ⅲ型：按 GA／T 714 规定的 HC 升温曲线测试，满足耐火极限不低于2．00h 的要求；

d） Ⅳ型：按 GB／T 9978．1 规定的升温曲线测试，满足耐火极限不低于2．00h 的要求。

## 5 一般要求

5 1 涂料中不应含有石棉等对人体有害的物质 涂层实干后不应有刺激性气味

5 2 涂料可用喷涂 抹涂 辊涂 刮涂和刷涂等方法中任何一种或多种方法涂装均匀 并能在自然环境条件下干燥固化。

## 7． 6 干密度

隧道防火涂料的干密度试验步骤如下

<!-- 第 3 页 -->

a） 先在规格为 $7 0 . 7 \mathrm { m m } \times 7 0 . 7 \mathrm { m m } \times 7 0 . 7 \mathrm { m m }$ 的试模内壁涂一薄层脱模剂，将拌和后的涂料注入试模内，插捣密实抹平，待基本干燥固化后脱模。 在规定的环境条件下，养护 7d 后，再放置在 $( 6 0 \pm 5 ) \mathrm { { ^ { \circ } C } }$ 的烘箱中干燥 然后放置在干燥器内冷却至室温 每次成型个试件。

b） 采用卡尺和电子天平测量试件的体积和质量，并按式（1）计算干密度。

$$\rho = \frac{m}{V}\tag{1}$$

式中 $: \rho ^ { - }$ ———干密度，单位为千克每立方米 $( \mathrm { ~ k g / m } ^ { 3 } )$ ；

m———质量，单位为千克 $( \mathrm { { k g } ) }$

V———体积，单位为立方米 $\left( \mathbf { m } ^ { 3 } \right)$ 。

c） 干密度结果应为5 个试件结果的算数平均值，精确到 $1 \mathrm { k g } / \mathrm { m } ^ { 3 }$ 。 如果5 个测试值中有1 个值超过平均值 时 应剔除后以剩下的 个值的算术平均值作为最后结果 如果 个值中再有超过平均值 ±15％的，则此组结果无效。

## 7．7 耐水性

隧道防火涂料耐水性试验步骤如下：

将 个制备好的隧道防火涂料试件短边朝下垂直浸入盛有自来水的玻璃容器中 浸入深度为试件长边的2／3；

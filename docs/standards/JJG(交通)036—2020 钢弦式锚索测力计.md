## 1 范围

本规程适用于钢弦式锚索测力计的首次检定、后续检定和使用中检查。

## 2 概述

钢弦式锚索测力计（以下简称“锚索测力计”）主要用于长期监测岩石高边坡、地下围岩、港口码头等工程中锚索张力。

锚索测力计由受力环、钢弦、专用电缆及线圈组成，其结构示意图如图1 所示。

说明：

1———受力环； 3———专用电缆；

2———钢弦； 4———线圈。

图1 锚索测力计结构示意图

## 4 通用技术要求

## 4.1 外观

锚索测力计各部分应连接牢固，其表面应无锈斑及裂痕，引出的电缆、护套应无损伤。

## 4.2 铭牌

锚索测力计应在其显著部位标明其型号、名称、生产厂家、出厂编号及日期等内容。

## 5 计量器具控制

## 5.1 检定条件

#### 5.1.1 检定环境条件

环境条件要求如下：

a） 温度： $2 0 ^ { \circ } \mathrm { C } \pm 5 \mathrm { ^ \circ C }$

b） 相对湿度：应不大于80％；

c） 周围应无影响检定结果的振动、冲击、电磁场及其他干扰源。

#### 5.1.2 检定设备及要求如下：

a） 钢弦频率测定仪：分辨力0.01Hz，频率测量相对误差 ±0.05％；

b） 力标准机：0.5 级，力值测量范围覆盖锚索测力计测量范围。

#### 5.3.3 滞后检定步骤如下：

a） 锚索测力计在检定环境条件下放置不少于8h。

b） 钢弦频率测定仪通电预热不少于30min。

c） 连接锚索测力计和钢弦频率测定仪，安装锚索测力计在力标准机上，按满量程拉力对锚索测力计预拉3 次，静置5min 后进行正式试验。

d） 进程试验，读取拉力为零时钢弦频率测定仪的输出频率值，使用力标准机对锚索测力计按10％F·S 逐级加荷至满量程拉力值，每级拉力保持不小于1min，读取钢弦频率测定仪的输出频率值。

e） 回程试验，按10％F·S 从满量程拉力逐级卸荷至零点拉力，每级拉力保持不小于1min，读取钢弦频率测定仪的输出频率值。

f） 退回零点拉力值后，保持3min，读取拉力为零时钢弦频率测定仪的输出频率值。

g） 重复d） ～f）的步骤进行3 次循环试验，按式（1）计算第 $i ( i = 0 , 1 , 2 , 3 \cdots , 1 0 )$ 个检定点第 $j ( j = 1 , 2 , 3 \cdots , 6 )$ 次行程中锚索测力计灵敏度系数

$$
k _ {i j} = \frac {F _ {i j}}{f _ {0 j} ^ {2} - f _ {i j} ^ {2}}\tag{1}
$$

式中 $\colon k _ { i j }$ 第 i 个检定点第j 次行程中锚索测力计灵敏度系数 $( \mathrm { \ k N / H z } ^ { 2 } )$

$\boldsymbol { F } _ { i j }$ ———第 i 个检定点第j 次行程时力标准机示值（kN）；

$f _ { 0 j }$ ———拉力为零、第j 次行程时钢弦频率测定仪的输出频率值（Hz）；

$f _ { i j } ^ { \mathrm { ~ ~ } }$ ———第 i 个检定点第j 次行程时钢弦频率测定仪的输出频率值（Hz）；

h） 按式（2）计算 $k _ { i j }$ 的算数平均值；

$$
\bar {k} = \frac {1}{6 0} \sum_ {i = 1} ^ {1 0} \sum_ {j = 1} ^ {6} k _ {i j}\tag{2}
$$

式中： $\bar { k }$ ———所有检定点 $k _ { i j }$ 的算数平均值 $( \mathrm { \ k N / H z } ^ { 2 } )$ ；

i） 按式（3）计算零点与各检定点输出频率平方差的理论值。

$$
N _ {i} = \frac {1}{\overline{k}} \overline{F} _ {i}\tag{3}
$$

式中 $N _ { i }$ 第 i 个检定点在 次循环试验测量中零点与各检定点输出频率平方差的理论值 $\left( \mathrm { H z } ^ { 2 } \right)$ ；

$\overline{F} _ { i }$ ———第 i 个检定点在3 次循环试验测量中各力标准机示值的算数平均值（kN）；

j） 按式（4）计算零点第j 次行程的输出频率平方与第 i 个检定点第j 次行程输出频率平方之差。

$$
N _ {i j} = f _ {0 j} ^ {2} - f _ {i j} ^ {2}\tag{4}
$$

按式 计算滞后 ${ \boldsymbol { a } _ { i } } ^ { \prime }$ 取 ${ \boldsymbol { a } _ { i } } ^ { \prime }$ 中绝对值最大值为滞后的检定结果

$$
a _ {i} ^ {\prime} = \frac {\overline{N} _ {i J} - \overline{N} _ {i H}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{5}
$$

<!-- 第 3 页 -->

式中： $\overline{N} _ { i J }$ ———3 次进程测量各检定点对应的 $N _ { i j }$ 算数平均值 $\left( \mathrm { H z } ^ { 2 } \right)$

$\overline{N} _ { i H }$ ———3 次回程测量各检定点对应的 $N _ { i j }$ 算数平均值 $\left( \mathrm { H z } ^ { 2 } \right)$

$\bar { f } _ { 0 }$ ———3 次循环试验测量中拉力为零时钢弦频率测定仪的输出频率的算数平均值（Hz）；

$\bar{f} _ { 1 0 }$ ———3 次循环试验测量中满量程拉力时钢弦频率测定仪输出频率的算数平均值（Hz）；

#### 5.3.4 不重复度

不重复度的检定试验步骤与滞后的检定试验步骤 a） ～j）相同，按式（6）计算不重复度 ${ \boldsymbol { a } _ { i } } ^ { \prime \prime }$ ，取 $\boldsymbol { a _ { i } } ^ { \prime }$ 中最大值作为不重复度的检定结果。

$$
a _ {i} ^ {\prime \prime} = \frac {\left| \Delta N _ {R} \right|}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{6}
$$

式中： $\Delta N _ { R }$ ———3 次循环测量中各检定点输出频率平方差的最大值 $\left( \mathrm { H z } ^ { 2 } \right)$

#### 5.3.5 非线性度

非线性度的检定试验步骤与滞后的检定试验步骤 a） ～j）相同，按式（7）计算非线性 度 $L _ { i }$ ，取 $L _ { i }$ 中绝对值最大值作为非线性度的检定结果。

$$
L _ {i} = \frac {\overline{N} _ {L} - N _ {i}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{7}
$$

式中： $\overline{N} _ {L}$ ———3 次循环测量中各检定点的输出频率平方差的算数平均值 $\left( \mathrm { H z } ^ { 2 } \right)$ ；

#### 5.3.6 综合误差

综合误差的检定试验步骤与滞后的检定试验步骤 相同 按式 计算综合误差 $\varepsilon _ { i C }$ ，取 $\varepsilon _ { i C }$ 中绝对值最大值作为综合误差的检定结果。

$$
\varepsilon_ {i C} = \frac {N _ {i j} - N _ {i}}{\left| \bar {f} _ {0} ^ {2} - \bar {f} _ {1 0} ^ {2} \right|} \times 100 \% \mathrm{F} \cdot \mathrm{S}\tag{8}
$$

## 前 言

本标准按照 GB/T 1.1—2009 给出的规则起草ꎮ

本标准代替 JT/T 489—2003«收费公路车辆通行费车型分类»ꎬ与 JT/T 489—2003 相比ꎬ除编辑性修改外主要技术变化如下

———修改了载客汽车、载货汽车的术语和定义(见3.1 和3.2ꎬ 2003 年版的第3 章)ꎻ

———增加了专项作业车、挂车、乘用车列车、货车列车、半挂汽车列车、摩托车的术语和定义(见3. 3、3. 4、3. 5、3. 6、3. 7 和 3. 8)ꎻ

———修改了客车车型分类依据(见 4. 2. 2ꎬ2003 年版的 4. 2)ꎻ

———修改了1 类客车和2 类客车的分类界限值(见4.2.3ꎬ 2003 年版的5.1)ꎻ

———增加了乘用车列车和摩托车的分类(见4.2.3 和4.2.4)ꎻ

———增加了对货车列车、半挂汽车列车以及六轴以上货车的分类说明(见 4. 3. 2 和 4. 3. 5)ꎻ

———修改了货车车型分类依据(见 4. 3. 3ꎬ2003 年版的 4. 1)ꎻ

———增加了专项作业车的分类及其依据(见4.4)ꎮ

本标准由全国交通工程设施(公路)标准化技术委员会(SAC/TC 223)提出并归口ꎮ

本标准起草单位:交通运输部公路科学研究院ꎮ

本标准主要起草人 袁茂存 王燕弓 浦亮 董金松 吕安琪

本标准所代替标准的历次版本发布情况为:

———JT / T 489—2003ꎮ

本标准规定了收费公路车辆通行费的车型分类ꎮ

本标准适用于行驶在收费公路上的所有车辆ꎮ

## 3 术语和定义

GB 7258 界定的术语和定义适用于本文件ꎮ 为了便于使用ꎬ以下重复列出了 GB 7258 中的某些术语和定义ꎮ

### 3. 1

## 载客汽车 passenger vehicle

设计和制造上主要用于载运人员的汽车ꎬ包括装置有专用设备或器具但以载运人员为主要目的的汽车ꎮ

[GB 7258—2017ꎬ定义 3. 2. 1]

### 3. 2

## 载货汽车 goods vehicle

设计和制造上主要用于载运货物或牵引挂车的汽车ꎬ也包括:

a) 装置有专用设备或器具但以载运货物为主要目的的汽车ꎻ

b) 由非封闭式货车改装的ꎬ虽装置有专用设备或器具ꎬ但不属于专项作业车的汽车ꎮ

[GB 7258—2017ꎬ定义 3. 2. 2]

### 3. 3

## 专项作业车 special motor vehicle

## 专用作业车

装置有专用设备或器具 在设计和制造上用于工程专项 包括卫生医疗 作业的汽车 如汽车起重机、消防车、混凝土泵车、清障车、高空作业车、扫路车、吸污车、钻机车、仪器车、检测车、监测车、电源车、通信车、电视车、采血车、医疗车、体检医疗车等ꎬ但不包括装置有专用设备或器具而座位数(包括驾驶人座位 超过 个的汽车 消防车除外

[GB 7258—2017ꎬ定义 3. 2. 3]

### 3. 4

## 挂车 trailer

设计和制造上需由汽车或拖拉机牵引ꎬ才能在道路上正常使用的无动力道路车辆ꎬ包括牵引杆挂车 中置轴挂车和半挂车 用于

<!-- 第 1 页 -->

———载运货物ꎻ

———特殊用途ꎮ

[GB 7258—2017ꎬ定义 3. 3]

### 3. 5

## 乘用车列车 passenger / car trailer combination

乘用车和中置轴挂车的组合ꎮ

[GB 7258—2017ꎬ定义 3. 4. 1]

3. 6

货车列车 goods road train

货车和牵引杆挂车或中置轴挂车的组合ꎮ

[GB 7258—2017ꎬ定义 3. 4. 2]

3. 7

半挂汽车列车 articulated vehicle

半挂牵引车和半挂车的组合ꎬ也包括带有连接板的货车和旅居半挂车的组合ꎮ

[GB 7258—2017ꎬ定义 3. 4. 3]

### 3. 8

## 摩托车 motorcycle and moped

由动力装置驱动的ꎬ具有两个或三个车轮的道路车辆ꎬ但不包括:

a) 整车整备质量超过 400kg 的、不带驾驶室、用于载运货物的三轮车辆ꎻ

b) 整车整备质量超过 600kg、不带驾驶室、不具有载运货物结构或功能且设计和制造上最多乘坐2 人(包括驾驶人)的三轮车辆ꎻ

c) 整车整备质量超过 600kg 的带驾驶室的三轮车辆ꎻ

d) 最大设计车速、整车整备质量、外廓尺寸等指标符合相关国家标准和规定的ꎬ专供残疾人驾驶的机动轮椅车ꎻ

e) 符合电动自行车国家标准的车辆ꎮ

[GB 7258—2017ꎬ定义 3. 6]
